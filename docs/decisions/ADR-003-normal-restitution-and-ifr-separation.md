# ADR-003: 위치 기반 법선 반발과 회전 기반 IFR를 분리한다

- 상태: accepted
- 날짜: 2026-09-30

## 맥락

기존 충돌 trial은 각속도가 하나라도 없으면 전체 충돌을 제외했다. 그러면 중심 위치와 속도만으로 추정 가능한 법선 반발계수까지 불필요하게 잃는다. 또한 한 번 구한 `e_normal`을 접선 IFR 단계가 다시 최적화하면 계수의 자료 근거가 섞인다.

## 결정

- `normal_trials`는 검토된 고립 2체 충돌의 법선과 중심 전후 속도만 요구한다.
- `impact_trials`는 회전·접선 상태가 유효한 IFR 전용 자료다.
- `e_normal`은 별도 법선 단계에서 추정한다.
- IFR 단계는 그 값을 `fixed_e_normal`로 사용하고 `e_tangential`, `mu_collision`만 갱신한다.
- coefficient별 eligibility와 skipped reason을 저장한다.

## 결과

회전 결측 영상도 법선 반발 연구에 사용할 수 있다. 반대로 법선 자료가 있다는 이유만으로 IFR 계수를 만들지 않는다. 위치 기반 법선 검증과 회전 포함 IFR 검증을 결과에서 분리한다.

## 재검토 조건

법선과 접선을 동시에 추정하는 새 통계 모델을 도입하려면 별도 모델 ID, 식별성 분석, 독립 비교와 ADR이 필요하다. 기존 분리 결과를 조용히 대체하지 않는다.
