# ADR-004: 검색 후보와 운동학 사건 장벽을 분리한다

- 상태: accepted
- 날짜: 2026-09-30

## 맥락

근접·swept 검사는 충돌을 놓치지 않기 위한 넓은 검색 후보를 만든다. 이 후보를 그대로 미분 장벽으로 쓰고 모든 사건에 ±6프레임을 더하면 비접촉 통과와 깨끗한 자유운동 자료까지 제거된다. 수정 전 후보를 계속 사용하면 사용자의 승인·제외도 운동학에 반영되지 않는다.

## 결정

- 후보 범위, 전후 적합 범위, 충돌 경계, 명시적 사용 불가 범위를 별도 필드로 기록한다.
- 운동학과 자유운동은 검토가 반영된 최종 사건을 사용한다.
- `contact_frame_interval` 또는 `boundary_frame_interval`과 모든 `unusable_frame_intervals`의 합집합을 장벽으로 사용한다.
- `excluded`와 `noncontact_pass`는 장벽에서 제거한다.
- 새 경계 필드가 없는 구형 사건만 후보 범위를 보수적으로 사용한다.

## 결과

자유운동 자료 손실이 줄고 사용자 검토가 실제 파생량에 반영된다. 사건 검색 recall과 물리적 접촉 지속시간은 서로 다른 개념으로 유지된다.

## 재검토 조건

Schema 3.0에서 사람이 경계를 편집하면 동일 interval algebra를 CLI와 GUI가 공유해야 한다. 숨은 고정 padding을 다시 추가하지 않는다.
