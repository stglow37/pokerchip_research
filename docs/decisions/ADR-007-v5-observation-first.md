# v5: 자동 계측과 검증 상태의 분리

2026-10-01. 사용자가 v5에서 영상 입력 후 자동 처리를 명시적으로 요청했다. 기존 수동 시작 원칙은 수동 경로에 유지하며 자동 경로를 추가한다. 자동 선택을 사람 확인으로 위장하지 않는다.

- 자동 구간은 영상 형상·이동·가림 증거로 결정한다. Farkas/IFR 계수나 잔차는 선택에 사용하지 않는다.
- 분석 가능 구간과 외력 해제 검증은 별개다. 자동 구간은 탐색적 계측을 실행할 수 있지만, 해제 근거가 불충분하면 계수 공개/확정에 쓰지 않는다.
- 원본 PTS, 표시 회전, 프레임 번호를 보존한다. 검증된 seek만 허용하며 불일치·중복 PTS는 순차 읽기로 복귀한다.
- 위치와 회전의 유효 창은 따로 찾고 각각 결측·충돌 장벽을 넘지 않는다.
- 충돌 후보 탐색 폭으로 다중 충돌을 확정하지 않는다. 검토/변화점 경계를 먼저 구하고 최종 접촉 그래프를 재분류한다.
- 40 mm는 기본 공칭값이다. 독립 실측 불확도가 입력된 경우에만 반지름 사전정보를 피팅에 사용한다. 반복 6분할 인쇄를 절대 회전 정답으로 쓰지 않는다.
- 기존 schema 2.0에 추가 필드로 구현한다. 원본/기존 run은 보존한다. 물리식·부호는 변경하지 않는다.

검증 구분: 소프트웨어 회귀 / 합성 좌표 정답 / 실제 영상 프레임 확인 / 독립 물리 정확도. 실행 성공을 정확도로 표시하지 않는다.

독립 라벨 계약: source_sha256, session, frame_index(0 기반), release_last_contact/release_first_clear, 중심·윤곽 클릭과 허용 범위, 충돌 last_pre/first_post, 관측 가능한 표식·가림·이탈·정지. C007 적색 고무줄은 별도 영상 증거로 확인하며 모델 잔차로 정답을 선택하지 않는다. 학습용 영상과 평가 영상은 파일 단위로 사전 분리한다.

필수 회귀 사례: 시작→끝/끝→시작/탐색 후 핀 유지, 동일 프레임 seek, 오래된 요청 취소, 4개 짧은 원호, 표식 결측 근처의 별도 각속도 창, 후보 중첩하지만 실제로 분리된 연속 충돌, 보정 내부 일관성과 독립 길이 검증 구분.

실제 영상 재검증에서 다음 결정을 추가했다.

- 추적 재연결 범위는 누락된 시간에 따라 제한적으로 커진다. 고정 90 px 게이트는 빠른 발사 직후 흐림을 지나 다시 나타난 칩을 계속 거부했다. 예측 위치를 관측으로 저장하는 방식으로 해결하지 않았다.
- 원 윤곽이 측정 가능하지만 잔차가 큰 프레임은 낮은 신뢰도로 보존한다. 이 자료는 충돌 위치 확인에는 보일 수 있으나 미분·계수 피팅에서 정상 관측과 동등하게 사용하지 않는다.
- 위치 변화점은 시간·위치가 연속인 두 직선의 잔차로 찾는다. 직전/직후 충돌이 공유하는 칩의 관측 창을 잘라 앞 충격이 뒤 충격의 추정에 섞이지 않게 한다. Farkas/IFR에 잘 맞는 충돌 시각을 역으로 고르는 방법은 사용하지 않는다.
- 수치 게이트를 통과한 자동 충돌은 `automatic_exploratory_not_human_reviewed`로 피팅에 사용할 수 있다. 경계 폭, 전후 표본, 접근 속도 신호, 법선 불확실성이 기준이며 반발계수가 원하는 범위에 들어온다는 이유로 사건을 선별하지 않는다. 물리적 부적합·경계해·식별성은 피팅 이후 별도로 검사한다.
- 법선 반발은 회전 없이 위치 전후 상태로 추정하며, 양쪽 속도의 오차를 넣은 EIV를 사용한다. 회전 포함 IFR은 별도 조건을 요구한다. 접선 반발과 마찰의 분리를 자료가 뒷받침하지 않으면 값을 공개하지 않는다.
- 충돌 시각 환산 covariance는 상태 변환 Jacobian을 거친 조건부 값이다. 바닥 마찰의 불확실성과 공유 보정 오차를 포함한 완전한 신뢰구간으로 설명하지 않는다.

v5의 검증 결과와 잔여 한계는 `validation/test-records/v5/REPORT_KO.md` 및 `docs/development/V5_REQUIREMENTS_KO.md`에 기록한다. 모든 자동 실패가 해결되었거나 실제 물리 정확도가 입증되었다는 릴리스 표현은 사용하지 않는다.
