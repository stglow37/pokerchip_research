# ADR-008: v6 경고 포함 계산·계층 집계·관측 통합

상태: 채택·구현 및 소프트웨어 인수 확인 완료(2026-10-06). 사용자 요청에 따라 v5에서 분기했다. 독립 물리 정확도 검증과 공개 릴리스/병합은 별개다.

## 결정

관측 사용 가능성과 품질 경고를 분리한다. 유한한 필수 입력이 있으면 흐림·부분 윤곽·불안정 원 피팅·약한 접근 신호·넓은 충돌 경계·미완료 검토를 포함한다. 경고 자체로 관측을 보간하거나 별도 페널티를 부여하지 않는다. 실제 결측·ID 모호성·사용자 제외·회전 alias·특이 회귀·다중접촉·바닥 이탈은 해당 계산을 차단한다.

경고는 계산 대상 프레임에 재귀적으로 붙여 퍼뜨리지 않는다. 실제 입력 칩/프레임 참조의 합집합을 전달한다. 관측 자체의 경고와 회귀·모델 진단 경고를 구별한다. 자동 포함은 사람 승인이 아니다.

마찰은 실제 시간 0.25초 비중첩 구간을 기본으로 모든 적격 구간을 피팅한다. 구간→영상→세션→전체 평균은 길고 구간이 많은 영상의 지배를 방지하려는 집계 선택이며, 더 빠르거나 더 정확하다는 보장은 아니다. 법선 대표값은 기존 robust EIV 회귀를 유지하고 사건별 원비율을 별도로 보존한다. 접선 두 계수는 다사건 식별성을 유지한다. Farkas/IFR 물리식·부호·단위는 바꾸지 않는다.

재표본은 독립 세션, 세션이 하나면 영상 단위로 수행한다. 후자는 동일 세션 내 변동이다. 묶음 하나는 집계 신뢰구간을 만들지 않는다. 기본 200회는 저장된 구간 추정 재집계/법선 재회귀이며, 접선 전체 단계 재피팅은 기본 꺼짐이다. 입력되지 않은 공통 오차는 검증된 0이 아니다.

통합은 읽기 전용 검사→명시적 검토본 선택/클립 제외→새 프로젝트 관측 가져오기→재추정 순서다. 분석자별 계수를 평균하지 않는다. 동일 원본의 중복 검토본을 독립 표본으로 세지 않는다. 부모 원본을 공유하는 학습/검증을 차단한다.

## 호환과 검증

schema 2.0 선택 필드와 기존 import·파일명을 유지한다. 정책 버전을 검토 근거에 추가하고 과학 코드 digest로 캐시를 무효화한다. 기존 결과·원본·동결 archive를 변경하지 않는다. 구현 상태와 실제 시험 증거는 v6 실행 기록을 따른다. 소프트웨어 시험 및 개발 ZIP 재계산은 독립 물리 검증이 아니다.
