# ADR-010: 영상 뒤쪽의 격자로 자동 보정 복구

2026-10-10. 연구용 로컬 개선본 6.0.0+audit1. 공식 GitHub 릴리스가 아니다.

E095의 초반 0~90프레임은 격자 잔차 기준을 넘었고, 150프레임만 통과했다. 기존 최대 150프레임 탐색으로는 두 프레임 이상의 일치를 얻지 못했다. 처리는 완료됐지만 세계 좌표는 없었고, 바닥 영역이 없는 구간 탐색은 영상 시작을 잘못 골랐다.

기존 초반 표본에 전체 영상의 20/35/50/65/80/95% 지점을 추가한다. 이미 세 프레임이 합의하면 조기 종료한다. 잔차 1mm, 격자선 수, 긴 방향 확인 및 변환 기저 3% 합의 기준은 완화하지 않는다. 모델 계수와 예측 오차로 보정 프레임을 선택하지 않는다. 영상별 평면 변환을 유지하며 다른 영상의 외부표정을 복사하지 않는다.

후반 일관된 격자에서 복구하는 회귀시험과, 후반 변환이 불일치할 때 실패 상태를 유지하는 시험을 추가했다. E095 실제 재측정에서는 [150,167,310]프레임이 합의했고, 사용 구간이 [0,478]에서 [231,478]로 수정됐다. 이는 독립 거리 정확도 인증이 아니다.

원본 영상과 수정 전 run은 보존한다. 새 코드 해시로 재처리하므로 이전 캐시와 과학적 출처를 구별할 수 있다. schema와 CLI/GUI 계약은 바꾸지 않는다.
