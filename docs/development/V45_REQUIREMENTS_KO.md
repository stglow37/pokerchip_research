## 검수 범위의 경계

- 전체 영상 49개 시험은 자동 검출·저장 통합 진단이다. 시작을 임의 승인하거나 이 자료를 물성 피팅에 넣지 않았다.
- 별도 3개 시험은 TEST1의 기존 사용자 시작 지정과 원본 해시를 검증하여 사용한다. 개발에 반복 사용한 영상이므로 새 독립 연구 검증 자료가 아니다.
- Farkas의 균일 압력·평면 접촉 가정, IFR 회전 확장의 실험 타당성은 소프트웨어 변경만으로 입증되지 않는다.
- 영상에 없는 회전 정보, 노출 중의 충돌, 다중 동시 접촉은 자동으로 값을 채우지 않는다. 검토/보류 이유가 결과다.
- 최소 화면 960×680을 지원하지만 세로 FHD 영상의 세밀한 점 선택에는 전체화면을 권장한다.

## 후속 개발 시 첫 확인

`validation/test-records/v45/REPORT_KO.md`와 실패 없는 시험 결과를 먼저 확인한다. 실제 연구 다음 단계는 새로 촬영한 영상에서 사람이 확인한 중심·가장자리 방향과 독립 길이를 확보하여 절대 측정 오차를 평가하는 것이다. 이것은 v4.5의 실행 오류 수정과 구별한다.
