# v5 요구사항 대응과 적용 범위

기준: 2026-10-01 사용자 요청, 이전 개선 감사, `VIDEO_FRAME_ACCESS_AND_AUTO_INTERVAL_PLAN_KO.md`. 참고 지시문보다 최신 사용자 요청의 자동 처리를 우선한다.

| 요청/문제 | v5 처리 | 검증/한계 |
|---|---|---|
| 영상만 추가하고 자동 분석 | 영상 기반 움직임·윤곽의 coarse/fine 구간 제안, 자동 적용, 개수 인식, CSV·Excel 저장 | 외력 해제를 독립 확인한 것과 구분. 불확실한 구간은 확인 대상으로 남음 |
| 뒤쪽 프레임으로 이동할 때 느림 | 표시 순서 PTS·키프레임·픽셀 체크섬 색인, bounded LRU, 오래된 요청 중단 | 최초 색인은 전체 영상을 읽음. 손상/중복 PTS는 순차 읽기 |
| 끝을 먼저 지정해야 시작 지정됨 | 탐색 커서와 고정 시작 분리 | 시작→끝 / 끝→시작 / 고정 후 탐색 GUI 시험 |
| 원 피팅이 내부 무늬·격자에 끌림 | consensus 초기화, robust 거리 잔차, outlier 제거 후 재적합, 실제 각도 구간 점유율 | 원 경계 후보 자체가 모션블러면 참 중심을 보증하지 못함 |
| 원근 보정 후 표시한 원이 어긋남 | 최종 월드 원을 원본 영상에 역투영. 중심·반지름·공분산·윤곽을 같은 최종 모델에서 산출 | 높이·렌즈·평면의 공통 오차는 조건부 covariance 밖 |
| 검정 몸체와 파란 가장자리 합쳐짐 | 칩 내부 밝기에 상대적인 색 임계값, 보정된 평면에서 표식 반지름 판정 | 어둡거나 작은 표식은 여전히 결측 가능 |
| 표식이 맞는지 안 보임 | 가장자리/안쪽 십자·중심 연결선·각도 상태, 화면 및 내보내기 표시 | 색은 역할 표시이며 정확도 확률 아님 |
| 흐림 이후 재등장 칩을 추적하지 못함 | 누락 시간에 따른 association 범위 확대, 형태 근거의 초기 위치 추적 허용 | 순간 먼 점프는 허용하지 않으며 칩 번호와 실물 ID 구분 |
| 충돌 하나를 두 사건으로 나눔 | 짧은 관측 누락을 걸친 근접 후보 병합 | 관측 없는 구간의 실제 접촉을 확정하지 않음 |
| 넓은 거리 후보 = 넓은 충돌 시각 | 연속 위치 변화점 + 전후 위치 연속 조건, 근접 후보와 전후 경계 분리 | 비슷한 경계는 두 프레임 이상 범위로 표시 |
| 변화점이 흐림 때문에 충돌 뒤로 밀림 | 앞쪽 gap 전체를 이유로 후보를 버리지 않고 연속 suffix/prefix 사용 | 실제 모션블러 노출은 충돌 전·후가 한 프레임에 섞일 수 있음 |
| 후속 충돌/다중접촉 오분류 | 경계 확정 후 최종 접촉 그래프, 이웃 충돌이 회귀 창에 섞이지 않게 제한 | 동시 다중접촉을 쌍별 IFR로 억지 계산하지 않음 |
| 회전 결측 한 장 때문에 주변 전체 결측 | 위치 창과 각도 창 분리, 각도는 연속 관측만 사용 | 표식 결측을 예측 각도로 채우지 않음 |
| 완전 정지·이탈 | 수동 칩별 종료/바닥 이탈/재진입/정지 기능 유지, 완전 정지 후 피팅 제외 | 자동 끝은 마지막 안정 관측 기반. 완전 정지 여부·재진입 의미를 항상 자동 확정하는 상태기계는 아직 아님 |
| 영상에 바둑판을 같이 보고 싶음 | 실제 원본 바둑판 위 궤적, 동일 축척 평면 사진 저장 | 9개 큰 점을 새 자동 캘리브레이션 기준점으로 사용하지 않음 |
| 40 mm와 6개 무늬 활용 | 공칭 지름을 후보 반경 범위에 활용, 독립 실측 반지름+σ가 있을 때만 연속 피팅 prior 사용 가능 | 반복 6분할 무늬만으로 절대 방향을 만들지 않음. 6개 섹터용 별도 학습 검출기는 도입하지 않음 |
| 자동 계수 계산 | 수치 게이트를 통과한 충돌만 탐색 피팅에 포함. 법선/접선 입력 요건 분리 | 자동 검토를 사람 승인으로 저장하지 않음 |
| 충돌 전 속도도 오차가 있음 | 법선 피팅에 pre/post σ를 나눈 EIV 적용 | 법선 방향·공통 보정 불확실성까지 완전한 사후분포는 아님 |
| IFR 시각 환산 σ 문제 | Farkas 상태 재구성의 Jacobian covariance를 충돌시각으로 전달 | μ 고정 조건부이며 모델 오차와 공유 오차 미포함 |
| 계수 구하기와 고정 검증 | 원본/세션/물성 provenance, 동일 원본·같은 부모 클립 누수 거부 | 개발 중 본 영상들은 논문 최종 독립 평가군이 아님 |
| 계수 계산 진행률 | 단계와 최적화 평가 횟수 기반 %, 취소 처리 | %는 정확한 남은 시간 추정이 아님 |
| 버튼 과다·작은 영상 | 기본 3개 화면, 수정 작업 메뉴, 고급 도구 접기, F11 | Windows offscreen Qt 렌더 및 이벤트 시험. 모든 모니터/DPI/테마 조합은 미검증 |
| 과거 결과가 최신처럼 나옴 | 결과 저장 전 stage fingerprint 비교, 오래된 결과는 재분석 필요 | 과거 run 자체는 보존 |

## 정확도에 관한 판단

이 버전은 자동화와 실패 검출을 개선한 연구용 분석 프로그램이다. 모든 가림·빠른 회전·발사기 접촉·동시 충돌을 영상만으로 정확히 판정하는 것은 이번 자료로 입증하지 못했다. ‘미측정/낮은 신뢰도/자동 탐색/사람 확인’을 분리하는 것이 배포 조건이다.

실제 mm·rad 오차와 계수 CI의 경험적 신뢰도를 구하려면 개발에 사용하지 않은 영상, 복수 작업자의 원 중심·표식·충돌/해제 라벨, 독립 길이/시간 검증이 더 필요하다. 실행 성공률이나 원 적합 잔차를 그 정확도 대신 쓰지 않는다.
