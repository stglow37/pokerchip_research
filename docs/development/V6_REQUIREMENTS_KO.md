# v6 요구사항 인수 확인

2026-10-06 소프트웨어 인수 확인 완료. 목표는 경고 포함 계산, 구간/사건별 계수와 신뢰도, 여러 분석자의 관측 통합이다. 아래는 현재 구현·회귀시험·실제 ZIP 재계산·진입점/산출물의 근거다. 독립 물리 정확도 확인, 공개 릴리스 및 main 병합은 별개다.

## 1. 공통 계산 정책

- 구현: `core/observation_policy.py`, `analysis/kinematics.py`, `models/contact_states.py`, `application/pipeline.py`. 품질 경고는 입력 차단과 분리하고, 기존 공분산/가중치를 유지한다. 실제 의존 칩/프레임 합집합으로 경고를 전달한다.
- 검증: `tests/regression/test_v6.py`의 경고만 다른 관측 숫자 일치, 필수 입력/ID/바닥 장벽, 회전 누락/비유한 각도의 위치 부분 계산, 보정 없는 픽셀 계산, 자동 충돌과 사람 승인 분리 시험.
- 실제 근거: ZIP E120의 212·221 관측은 동일 측정 경고를 유지하면서 속도와 각속도를 산출했다. 새 결과만 저장했다. 상세 수치와 원인 참조는 [실행 기록](../../validation/test-records/v6/REPORT_KO.md)을 따른다.
- 기존 자유운동 dataset/탐색 preview도 `usable(...,orientation=True)`와 명시적 `fit_enabled`를 적용한다. preview의 시간 역행/중복·회전 alias는 미산출 이유를 기록한다. dataset에서 제외/비유한 각도를 넘어 이어붙이지 않는 회귀 2개를 포함한 전체 198개가 통과했다.

## 2. 계수 추정

- 마찰: `models/study.py:free_trials`, `models/coefficient_statistics.py:fit_segments/hierarchy`. 실제 시간 0.25초, 비중첩, 짧은 꼬리 최소 24개, 최대 3구간 제한 제거. 경고·약한 운동 신호만으로 분할하거나 삭제하지 않는다. 충돌/결측/사용자 제외/표면 변경은 장벽이다.
- 각 구간은 Farkas 초기 상태와 μ를 피팅하고 잔차·수렴·rank·경계·경고·입력·시간을 저장한다. 특이/미수렴 후보는 보존하되 대표값에서 제외한다. 구간→영상→세션→전체 산술평균, 중앙값/조건부 역분산 비교, 선택적 공통 피팅 시간을 제공한다.
- 법선: 사건별 원 반발비와 전후 sigma를 보존하며 약한 신호나 범위 밖 비율을 삭제하지 않는다. 대표값은 기존 robust EIV 회귀다. 경계 후보는 경고와 함께 저장한다.
- 접선: 사건별 접촉 미끄럼·회전 변화·채널별 충격량·잔차는 관측 진단이다. e_t/μ_c는 다사건 피팅과 식별/허용성 검사를 통과해야 대표계수로 제공한다. 미산출 최적화 후보는 진단으로 구별한다.
- 시험: 구간 전체 범위·꼬리·계층 평균·약한 신호 유지·특이 후보·원 법선비/경계 후보, 기존 물리/피팅/고정 검증 회귀. 실제 ZIP은 마찰 16후보 중 14구간, 법선 3건을 사용했다. 접선 적격 2건은 숫자를 강제로 만들지 않았다.

## 3. 신뢰도·표시·내보내기

- 반복성 분포/표준편차, 영상 제외 민감도, 조건부 공분산, 별도 영상 고정 예측 오차를 분리한다.
- 기본 cluster bootstrap 200회: 세션 재표본, 세션 하나면 영상 재표본/동일 세션 내 변동, 묶음 하나면 CI=null. 마찰은 저장된 추정 재집계, 법선은 재회귀다.
- 고급 접선 재피팅 기본 0회. 실행 시 관측 재표본→마찰→법선→접촉 상태→접선의 전 단계를 수행하고 제공된 공통 길이/시간 sigma만 반영한다. 미입력 오차는 검증된 0이 아니다.
- 시험: 재표본 재현성·그룹 수/범위·단일 그룹 미산출, `test_v6_bootstrap.py`의 선행 단계 재실행·계수 전달·명시적 제외 유지. 실제 ZIP은 접선 식별 자료가 부족해 접선 CI coverage를 독립 검증하지 않았다.
- UI와 CSV/Excel/JSON: 관측 경고와 실제 입력 참조·수/비율·항목별 상태/이유·영상/세션 수. `constants.json`과 기존 파일명을 유지하고 구간별_마찰계수.csv, 충돌별_계수.csv, 계수_신뢰도.csv, 계수_요약.xlsx를 추가한다.
- 실제 export 구조/GUI 진입점 확인은 실행 기록에 남긴다. Qt offscreen smoke는 모든 DPI/마우스/키보드 사용성을 검증한 것이 아니다.

## 4. 분담 분석·통합

- `application/integration.py`가 제출 manifest 생성, 읽기 전용 사전 검사, 명시적 채택/제외, 새 프로젝트 가져오기, 관측에서 계수 재산출을 담당한다. CLI/GUI는 동일 서비스를 호출한다.
- 원본 해시/채택 run/현재 분석 상태·공통 설정·검토 차이·중복·부모 클립 중복·학습/검증 누수를 검사한다. 동일 원본은 한 검토본만 채택한다. 설정 불일치는 재분석 대상이며 영상별 보정 근거는 보존한다.
- 새 experiment/run namespace와 ID 대응, imported_manifest 및 모든 제출본의 채택/제외 출처를 보존한다. 기존 원본·run·계수는 덮어쓰지 않는다. 분석자 계수 평균은 하지 않는다.
- 시험: `tests/integration/test_v6_integration.py`의 읽기 전용/중복/검토 선택/부모 누수/역할 충돌/누락·stale/새 ID 및 재산출 호출.
- 촬영 세션 ID 누락은 제출 생성과 통합 사전 검사에서 차단한다. 누락 자료로 새 목적지를 생성하거나 기존 제출 manifest를 덮어쓰지 않는 회귀시험도 통과했다.
- 실제 경로: 4영상 전체는 설정 불일치로 차단됐고, E120만 명시적으로 채택한 별도 프로젝트에서 관측 가져오기·export 재생성·계수 재산출을 확인했다. 연구용 최종 통합 결정으로 주장하지 않는다.
- 운영 규약: [분담 분석 가이드](../operations/DISTRIBUTED_ANALYSIS_V6_KO.md). 제출에는 원본/부모/세션·분석자·채택 run·설정·수정 이력이 필요하며 계수 파일만으로 통합하지 않는다.
