# 포커칩 연구 프로그램 v3.5

시작 프레임 직접 확인 → 영상 측정 → 공통 물리계수 피팅 → 고정 계수 검증.

실행은 `RUN.cmd`, 최초 설치는 `SETUP.cmd`입니다. 자세한 설명은 `docs/V35_QUICKSTART_KO.md`를 읽으세요.

검정 원판과 테두리 색 표시·내부 스티커를 사용합니다. 삼성 240fps, 전체 1/8배속(파일 약30fps) 기본값입니다. 12g/지름4cm, 격자22.5×23.8889mm. 사람의 시작 확인 없이 실제 영상 분석을 시작하지 않습니다.

v3의 결과를 자동으로 확정 계수로 승격하지 않습니다. 영상 측정과 모델 환산을 별도 저장하며, 접선 계수 식별 실패 시 적용을 보류합니다. 광학·시간·표식·접촉 모델의 실험적 정확도는 별도로 검증해야 합니다.
