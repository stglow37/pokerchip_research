## 관측 처리의 변경

Hough 원 후보만 쓰던 경로에 검정 칩 내부의 어두운 연결영역 후보를 추가했습니다. 후보는 위치 제안일 뿐이며 최종 측정은 기존의 원본 영상 subpixel 경계·robust 원 피팅으로 수행합니다. 격자/그림자가 원처럼 보이지만 원 경계 오차가 큰 경우를 거릅니다.

개수 추정에서는 같은 칩의 중복 후보를 가림 물체로 잘못 취급하지 않도록 수정했습니다. 명목 지름이 같은 칩들의 크기 군집을 사용해 작은 원형 표식을 칩과 혼동하는 경우를 줄였습니다. 강한 원근으로 칩마다 크기가 크게 다른 장면에서는 이 가정이 맞지 않을 수 있어 직접 개수/분석 범위를 지정해야 합니다.

기본 모드의 칩 번호는 위치 연속성에 따른 추적 번호입니다. 동일 색 표식의 여러 칩도 궤적을 추적할 수 있지만, 장시간 가림 후 같은 실물임을 증명할 수는 없습니다. 모호한 배정은 알려지지 않은 번호로 남기고 검토 대상으로 표시합니다. 영상 간 실물 ID를 자동 대응하지 않습니다.

기본 회전각의 기준은 가장자리 색 표시 방향입니다. 중심 스티커를 회전 레버암으로 사용하지 않습니다. 표식이 흐리거나 여러 개로 보이면 각도/각속도를 비울 수 있습니다. 최대 회전 가정은 근거 없이 ‘실측 상한’으로 바꾸지 않고 조건부로 기록합니다.

보정이 없어도 픽셀 위치와 시간 조건에 따른 픽셀 속도를 저장합니다. 실제 거리 보정이 잠정이면 m 단위 결과에도 `provisional` 상태를 기록합니다. 측정 0행은 실패로 분류합니다. 한 영상 실패가 다음 영상 처리를 막지 않습니다.

## 보정 상태의 의미

자동으로 얻은 같은 판의 미사용 교차점 오차는 **내부 일관성**입니다. 독립적인 절대 거리 정확도와 같지 않습니다. 인쇄가 잘못 축소됐어도 그 판만으로는 알아낼 수 없기 때문에 기본 상태는 `provisional`입니다. 사용자가 별도로 측정한 길이/좌표·시간 기준을 입력하는 정밀 검증 경로를 유지했습니다.

바닥 확인란은 판이 바닥에 있고 카메라가 동일하다는 사용자의 실험 조건 확인입니다. 영상만 보고 판이 실제로 바닥에 닿았는지 완전히 판별하는 기능은 아닙니다. 기존 보정 결과는 원본 해시와 바닥 확인 조건이 같을 때 재사용합니다.

## 물리모델과 피팅

Farkas 자유운동, IFR 고립 2체 충돌, 세션 분할, EIV, bootstrap, 모델 비교 코어는 v2의 검증 경로를 유지했습니다. 이번 개수 확장은 동시 다체 충돌 모델을 새로 구현했다는 뜻이 아닙니다. 동시에 여러 접촉이 겹치면 고립 IFR 피팅에 넣지 않습니다.

자동 측정과 검증된 계수 추정을 분리했습니다. 보정과 시간 조건이 잠정이고 충돌이 미확인인데 마찰/반발계수를 자동으로 연구 결론처럼 확정하지 않습니다. 이번 기본 자동 버튼은 **영상 측정·검토 목록·데이터 저장**을 끝냅니다. 물리계수 계산은 검증된 자료를 모은 후 선택 화면에서 실행합니다.

## 유지한 제한

- 실제 삼성 FHD240 원본으로 동적 정확도·rolling shutter 영향·압축 편향을 새로 검증하지 않았습니다.
- 과거 60fps 자료와 합성 자료는 새 실험의 정확도 보증이 아닙니다.
- 모든 칩이 보이지 않는 영상의 총 칩 수, 초고속 회전의 alias, 가림 뒤 실물 ID는 항상 자동 확정할 수 없습니다.
- 조명·표식 크기·초점에 따라 검출 실패가 발생할 수 있습니다. 확인 사진과 프레임 검토가 남아 있습니다.
- Python 소스 배포이며 독립 EXE 빌드와 깨끗한 새 PC 설치 시험은 하지 않았습니다.
- 렌즈 전체 공분산·계층 Bayesian·지속 접촉·3D 들림은 추가 구현하지 않았습니다.
