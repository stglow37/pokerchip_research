## FHD 합성 4칩 전체 과정

보정 영상과 1920×1080 실험 영상, 파일 30fps·실제 시간 240fps를 사용했습니다. 48프레임 × 4칩의 정답은 렌더러 좌표/각도입니다. 자동 보정 결과는 절대 실측 검증이 없는 잠정 상태로 유지했습니다.

| 항목 | 결과 |
|---|---:|
| 자동 개수 | 4 |
| TP / FP / FN | 192 / 0 / 0 |
| 중심 2D RMSE | 0.095918 px |
| 회전각 MAE | 0.174023° |
| 연속 라벨 프레임 사이 번호 교환 | 0 |
| 각속도 계산 행 | 192 |

번호는 영상 내 임의 추적 번호이므로 첫 프레임에서 생성기 물체 ID와 한 번 대응시킨 뒤 고정했습니다. 이후 프레임마다 번호를 다시 맞추지 않았습니다. 좌표와 각도 정답은 생성기의 값을 그대로 사용합니다. 이 규칙은 예제 라벨의 `initial_id_gauge`와 `identity_policy`에 기록했습니다.

**합성 결과를 실제 스마트폰 정확도로 해석하면 안 됩니다.** 실제 센서, 흔들림, rolling shutter, 가림, 흐림, 인쇄 오차의 검증을 대신하지 않습니다. 합성 보정판과 실제 칩 높이의 차이도 실험에서 따로 확인해야 합니다.

## E: 과거 60fps 영상

원본 두 개를 읽기 전용으로 사용했고 E: 파일을 변경하지 않았습니다. 배율 1, 촬영 60fps 조건으로 분리했습니다. 새 보정판 영상과 연결하지 않았으므로 m 단위 결과는 비워 두었습니다.

| 영상 | 자동 개수 제안 | 자동 관측 행 | 상태 |
|---|---:|---:|---|
| 1개_004.mp4 | 1 | 66 | complete |
| 2개_001.mp4 | 1 | 114 | complete |

실제 두 칩 예비 영상은 자동 개수가 1개로 제안되는 한계를 확인했습니다. 발사기 가림과 빠른 이동 때문에 깨끗한 원이 동시에 보이는 근거가 부족했습니다. 칩 개수를 직접 2로 지정하여 재분석한 결과는 **139 / 242개 관측 기회**입니다. 이것은 정답 recall이 아닙니다. 실제 데이터셋 정확도나 모든 구간의 ID가 올바르다고 주장하지 않습니다.

과거 영상에 새 표식이 없거나 회전 안전 상한이 맞지 않는 구간의 각속도를 임의로 채우지 않았습니다. 숫자가 비어 있는 이유와 의심 프레임을 저장했습니다.
