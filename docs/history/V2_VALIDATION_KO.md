# v2 검증 기록과 해석 범위

검증 환경: Windows x64, Python 3.14.6. 기존 가상환경의 고정 의존성을 사용했으며 `pip check`에서 의존성 충돌이 없었습니다. 새 노트북의 clean install 시험과 EXE 빌드는 수행하지 않았습니다.

## 자동검사

64개 테스트가 통과했습니다. 최종 기록은 `validation_v2/pytest.xml`, `verification_summary.json`입니다. 포함 항목은 다음과 같습니다.

- Farkas 면적적분/극한/순수운동/정지/에너지/수렴
- IFR 질량비/초기 spin/대칭성/에너지·운동량/분기
- 통합 solver의 프레임 사이 충돌과 unsupported 다중접촉
- PTS·배속·미확정 시간·노출 end·독립 clock
- intrinsic/plane holdout, 원 피팅, 표식, alias, 이벤트 구간
- 전체 assignment 대안 모호성, 검정 칩 대비, 빈 격자 거부
- EIV 최적 상태와 보고 진단 일치, 정규화 법선, correlated residual whitening
- robust profile의 nuisance 재최적화, locked split 누수 차단
- 독립 라벨 false negative 계산, 정답 잠금, v1 백업 migration
- GUI 합성 생성→분석→프레임 이동→중심 보정→undo/redo
- batch 취소/재개·실패 격리·원본 재연결·atomic write

Qt 자동조작과 저장한 화면을 확인했습니다. 실제 학생의 독립 사용성 평가는 아직 하지 않았습니다.

## FHD 240 fps / 전체 1/8배속 합성 검증

1920×1080, 120프레임, 검정 칩 3개, 두 색상 표식, 격자 배경, H.264 압축 조건입니다. 생성기의 실제 시간은 `i/240`, 저장 PTS는 `i/30`, 변환 배율은 8입니다. 따라서 마지막 프레임의 실제 시간은 `119/240 = 0.4958333…초`입니다. 영상 길이 표시와 마지막 프레임 timestamp는 한 프레임 차이가 날 수 있습니다.

| 지표 | 결과 |
|---|---:|
| 정답 chip-frame | 360 |
| TP / FP / FN | 360 / 0 / 0 |
| 검출 recall / precision | 1.0 / 1.0 |
| matched ID 정확도 | 1.0 |
| 라벨 프레임 사이 ID switch | 0 |
| 중심 median 오차 | 약 0.0895 px |
| 중심 2D RMSE | 약 0.1152 px |
| 회전각 MAE | 약 0.2928° |

정답 매칭은 중심 거리 ≤ 정답 반지름의 0.5배를 후보 gate로 사용하고 일대일 배정합니다. 위치 오차는 매칭된 관측의 중심에 대해 계산합니다. 검출 실패는 FN으로 따로 계산합니다.

위 수치는 합성 생성기와 지정한 촬영 조건에 한정됩니다. 실제 스마트폰 센서, rolling shutter, 빛반사, 가림, 심한 blur를 통과했다는 뜻이 아닙니다. 수작업 라벨의 불확실성과도 다른 조건입니다.

이전 생성기에서 supersampling pixel-center convention으로 약 0.47 px의 인위적 2차원 편향이 생길 수 있음을 발견해 수정했습니다. 그러므로 v1과 v2의 합성 오차 숫자를 그대로 비교해 detector가 그만큼 개선되었다고 주장하지 않습니다.

예제는 `examples/FHD240_demo/project.json`을 열어 확인할 수 있습니다. 원본 영상, 분석 결과, 정답 라벨을 함께 제공합니다. 실행 시간과 샘플 RAM 측정은 `fhd240_validation.json`에 기록되며 실물 50개 batch 성능을 대표하지 않습니다.

## 독립 합성 데이터의 계수 복원

순수 병진 해석식과 별도 충격량으로 생성한 noisy fixture, 세션 단위 학습/보류 분할을 사용했습니다.

| 계수 | 생성 정답 | 추정값 (반올림) |
|---|---:|---:|
| μ_b | 0.12 | 0.120153 |
| e_n | 0.72 | 0.719829 |
| e_t | -0.83 | -0.832655 |
| μ_c | 0.08 | 0.080293 |

수치 수렴·물리 허용·국소 식별이 통과했습니다. bootstrap 4회도 별도로 실행했지만 이는 실행 경로 확인입니다. CI 안정성이나 실제 실험 coverage의 검증이 아닙니다. 결과를 `fit_synthetic.json`과 `bootstrap_smoke4.json`에 구분해 저장합니다.

## 기존 실제 영상 2개 재검토

| 영상 | 자동 관측 행 / 전체 대상 | 해석 |
|---|---:|---|
| 1개_004.mp4 | 77 / 119 | 시간·거리·새 표식 미검증 |
| 2개_001.mp4 | 166 / 242 | 시간·거리·새 표식 미검증 |

승인된 물리 충돌 사건은 없습니다. 새 표식이 없는 과거 약 60fps 파일이므로 실제 시간 배율을 임의로 8로 바꾸지 않았고 계수 피팅에 사용하지 않았습니다. 관측 행 비율은 독립 정답 recall이 아닙니다. 이 결과를 실물 검출 정확도의 개선 증거로 주장하지 않습니다.

개발 중 컬러 검출 범위를 시험했을 때 격자 오검출로 행 비율이 100%처럼 보이는 사례를 확인했습니다. 사용자의 최종 조건에 따라 컬러 칩 지원을 제거하고 검정 칩 전용으로 확정했습니다. 잘못된 중간 결과는 최종 검증 수치에 포함하지 않습니다.

## 최종적으로 아직 필요한 연구 검증

1. 실제 삼성 FHD240 원본의 독립 clock와 프레임 보간 여부 확인
2. 새 두 표식의 정적·동적 독립 중심/각도 라벨
3. 실제 카메라 보정과 칩 두께·관성·반지름 실측
4. 충돌 전후 속도·spin, Farkas/IFR 계수, session holdout 재현성
5. 실제 50개 영상, 다른 PC, 장시간 실행과 사용자 평가

소프트웨어 검사가 통과했다는 것과 물리모델이 실제 실험을 설명한다는 것은 별개입니다. 프로그램은 이 구분을 화면과 결과 파일에 유지합니다.
