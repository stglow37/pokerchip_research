# 포커칩 v3.5 사용 안내

이번 버전은 영상 측정과 물리 피팅을 분리합니다. **사람이 시작 프레임을 확인하지 않으면 실제 영상 분석을 실행할 수 없습니다.** 파일에 저장된 기존 시작 구간만으로 확인을 대신하지 않습니다.

## 바로 시작

이 노트북에서는 창의 R&E 폴더의 `포커칩 v3.5 실행` 바로가기를 엽니다. 준비한 `0928 v3.5 새 분석`에는 영상과 보정 자료만 등록되어 있습니다. 예전 결과를 덮어쓰지 않습니다.

1. 목록에서 영상 하나 또는 여러 개를 선택합니다.
2. **시작 프레임 선택 · 필수**를 누릅니다. 목록을 더블클릭해도 됩니다.
3. 손·고무줄에서 벗어나 원판 경계와 표식이 보이는 프레임으로 이동합니다. 마지막 발사 외력이 끝난 이후여야 합니다. 원판들이 서로 다른 때 발사되면 마지막 발사 이후의 공통 자유운동 구간을 고릅니다. 그 전에 충돌한다면 현재 공통 시작 방식으로는 그 충돌을 분석할 수 없습니다.
4. 확인란을 체크하고 **이 프레임부터 분석**을 누릅니다. 여러 영상을 선택했다면 다음 영상 창이 차례로 열립니다.
5. **측정 시작**을 누릅니다. 결과 CSV·Excel과 확인 장면이 자동 저장됩니다.
6. 저장된 결과에서 경고 영상만 먼저 확인합니다. 필요하면 원본 위 중심·표식·충돌 장면을 검토하고 수정합니다.
7. 결과 화면에서 **영상 용도 나누기 → 계수 구하기 → 저장 계수로 검증**을 진행합니다.

시작을 너무 늦게 고르면 충돌 직전 자료가 부족해집니다. 가림이 끝난 뒤 가능한 이른 프레임을 선택하되, 흐림·외력 구간을 억지로 넣지는 마세요. 현재 시작 구간은 영상 전체에 공통입니다. 원판별 서로 다른 시작 시점 기능은 제공하지 않습니다.

## 마우스와 프레임 조작

| 조작 | 동작 |
|---|---|
| ← / → 또는 ◀ 1 / 1 ▶ | 한 프레임 이동 |
| ◀ 10 / 10 ▶ | 열 프레임 이동 |
| 시작 선택 창의 Shift+←/→ | 열 프레임 이동 |
| 프레임 번호 입력 | 원하는 원본 프레임으로 이동 (0부터 시작) |
| + / − 버튼 또는 마우스 휠 | 확대 / 축소 |
| 오른쪽 버튼 드래그 | 화면 이동. 측정점을 찍지 않음 |
| 전체 보기 / 오른쪽 더블클릭 | 화면 맞춤으로 복귀 |
| 조회 도구에서 왼쪽 드래그 | 화면 이동 |
| 중심·표식·격자 도구에서 왼쪽 클릭 | 원본 픽셀 좌표 지정 |

가운데 버튼은 필요하지 않습니다. 확대 상태에서도 원본 픽셀 좌표로 변환됩니다. 프레임이 로딩되는 동안은 시작 선택과 중심 수정이 확정되지 않습니다. 재생은 검토 편의를 위한 저속 재생이며 실제 실험 시간 측정에 사용하지 않습니다.

## 진행률 읽기

`3/10번째 영상 · 파일명`과 **현재 영상 %, 전체 작업 %**를 표시합니다. 영상별 단계에 보정·개수·추적·계산·저장 가중치를 둔 진행률입니다. 정확한 남은 시간 예측은 아닙니다. 보정 영상 처리와 물리 최적화는 별도 단계명으로 표시합니다. 현재 추적 프레임 번호도 표시합니다. 중단하면 완료 영상과 체크포인트를 보존합니다.

## 보정·기본값

보정 확인란과 촬영 조건은 첫 화면의 **보정 확인란·칩 규격·촬영 설정 펼치기**에 있습니다.

- 삼성 전체 1/8배속: 재생 PTS ÷ 8 = 실제 시간. 촬영 240fps / 파일 약 30fps.
- 기본 질량 12g, 지름 40mm. 변경 가능. 관성은 균질 원판 근사.
- 격자: 짧은 변 22.5mm, 긴 변 23.8889mm. 수직에 가까운 촬영에서 긴 영상 방향에 긴 치수 배정.
- ChArUco: 11×8칸, 칸15mm, 마커11mm. 제공된 PDF 그대로 사용.
- 롤링셔터 보정 없음. 픽셀·거리 보정과 시간 상태는 각각 기록.
- 기본 렌즈·기본 바닥 평면·영상별 격자 보정 상태를 구분. 기본 평면 미확정이어도 영상별 격자 보정은 성공할 수 있음.
- 원판 개수는 자동 제안이며 사람이 수정 가능. 칩 자체는 검정 몸체와 테두리/내부 표식 사용.

## 피팅과 검증

측정 단계는 마찰계수를 자동으로 맞추지 않습니다. 공통 계수 계산은 별도 버튼으로 실행합니다. 거리 보정이 없거나 오래된 결과는 사전 점검에서 제외 사유를 보여줍니다.

바닥 마찰은 자유운동의 위치·각도를 피팅합니다. 충돌 분석은 구한 바닥 마찰을 고정해 양쪽 관측을 Farkas로 맞추고 같은 충돌 시각의 전후 상태를 추정합니다. 원래 영상 측정과 **모델에 조건부인 환산 상태**를 구분해 저장합니다. 이것만으로 모델이 참임을 증명하지 않습니다.

IFR 접선 반발과 충돌 마찰이 분리되지 않거나 경계값에 붙으면 고정 적용을 보류합니다. 숫자가 없다는 것이 프로그램 고장이라는 뜻은 아닙니다. 검증 영상의 물리 계수는 다시 피팅하지 않습니다. 초기 상태 측정에 쓴 앞부분은 예측 오차 평가에서 제외합니다.

영상마다 충돌을 직접 확인한 뒤 충돌 확인란을 체크하세요. 비접촉 통과·동시 다중 접촉·측정 불충분 사건은 고립 2체 IFR 학습에서 제외합니다. 프레임 사이 충돌을 거리만으로 제외하지 않습니다.

## 결과 위치

- `results/전체_운동데이터.csv`: 전체 영상의 측정값
- `results/영상별_요약.xlsx`: 영상별 처리 상태
- `runs/.../export/observations.jsonl`: 원본 관측
- `runs/.../export/manual.jsonl`: 수동 수정 반영 관측
- `runs/.../export/trajectories.csv`: 구간별 운동량
- `results/계수_측정/.../constants.json`: 계수·학습 출처·제외 사유·접촉 상태 환산 기록
- `results/고정계수_검증/.../validation.json`: 고정 계수 예측 오차

관측 비율, 같은 자료에 맞춘 적합 오차, 다른 영상 예측 오차, 절대 측정 정확도는 서로 다릅니다. 자동 검출률 100%도 정답 위치 100%를 뜻하지 않습니다.

## 다른 노트북 / VS Code

Python 3.12~3.14에서 사용할 수 있습니다. 폴더를 압축 해제해 `pokerchip_research`를 VS Code에서 엽니다. `SETUP.cmd`를 한 번 실행한 뒤 `RUN.cmd`를 엽니다. 인터넷이 있어야 최초 의존성 설치가 가능합니다. 설치된 v3.5를 이동했다면 가상환경은 새로 설치하는 것이 안전합니다.

PowerShell에서 직접 실행하려면:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe run_gui.py
```

현재 배포는 Python 실행 패키지입니다. 독립 실행형 EXE로 패키징한 버전은 아닙니다.
