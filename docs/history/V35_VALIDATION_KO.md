# v3.5 변경 사항과 검증 기록

작성: 2026-09-28. Windows x64 / Python 3.14.6. 이 문서는 구현과 확인 범위의 기록이며 절대 정확도 인증서가 아닙니다.

## 이번 변경의 이유

이전 버전은 손·발사 장치가 있는 구간에서 자동 초기화를 시도했고, 영상별 거리 보정 실패와 실제 측정 정확도가 사용자에게 충분히 구분되어 보이지 않았습니다. 모든 오류를 하나의 검출 알고리즘으로 없애기보다, 사람이 외력이 끝난 시작 장면을 지정하고 측정과 물리 해석을 분리하도록 변경했습니다.

| 문제 | v3.5 처리 |
|---|---|
| 잘못된 초기 구간 | 시작 프레임·사용자 확인·원본 SHA256를 저장. 이전 interval만으로는 승인되지 않음. 원본이나 구간이 바뀌면 다시 선택 |
| 진행 상황 불명확 | 현재 영상 번호/전체 개수, 파일명, 현재 영상 및 전체 작업 %, 추적 프레임 표시 |
| 프레임 탐색 지연·오선택 | 순차 디코더와 크기가 제한된 캐시, 최신 요청 우선 처리. 로딩 중인 다른 프레임을 확인/수정하지 못하도록 차단 |
| 불편한 마우스 | 한 프레임·열 프레임·번호 이동, 확대/축소, 오른쪽 드래그 이동, 점 도구의 왼쪽 클릭 |
| 특정 프레임 격자 검출 실패 | 여러 프레임에서 계산한 거리 변환이 일치하는지 검사. 최저 오차 하나를 무조건 선택하지 않음 |
| 비접촉 통과에 반발계수 표시 | 명확한 간격과 상대 칩의 정지 유지 증거로 비접촉을 구분. 제외 사건은 계수 숫자를 숨김 |
| 프레임 사이 실제 충돌 누락 | 한 프레임의 원판 간격만으로 충돌을 배제하지 않음 |
| 관측 창 속도를 곧바로 접촉 속도로 사용 | 먼저 구한 바닥 마찰을 고정하고 양쪽 자유운동을 같은 충돌 시각으로 환산. 원본 측정은 보존 |
| 피팅 품질을 과대 해석 | 측정 경고를 속도 데이터까지 전달. 식별 불가능한 공분산은 0이 아닌 미확정. IFR 접선 계수가 경계/식별 조건을 만족하지 않으면 고정 적용 보류 |
| 분석 도중 물리 피팅이 자동 실행 | 기본 흐름은 측정·저장까지. 계수 측정 및 고정 검증은 별도 실행 |

## 자동 검증

전체 테스트 **92개 통과, 실패 0개**. `validation_v35_tests.xml`에 테스트별 기록이 있습니다. 한 건의 테스트 환경 경고가 있었으며 테스트 실패는 없습니다.

주요 범위: Farkas 극한·에너지·적분 비교, IFR 보존량·대칭·분기, 학습/검증 원본 중복 차단, 검증 단계 계수 고정, 시작 확인 및 변경 원본 차단, 진행률 단조성, 프레임 캐시 일치, 오른쪽 드래그의 측정점 미생성, 확대 좌표 변환, 측정 경고 보존, 식별 불가 공분산, 합성 충돌의 동일 시각 상태 환산입니다.

합성 자료에서 알려진 법선 반발계수 0.72를 환산 후 0.003 이내로 회복하는 회귀 검사를 포함합니다. 합성 검사의 통과가 실험 영상의 계수 오차 0.003을 뜻하지 않습니다.

설치된 실제 Windows 창에서 프로젝트 열기, 시작 선택 창, 한 프레임 이동, 확대, 확인하지 않은 채 취소를 확인했습니다. 오른쪽 드래그와 점 선택 분리는 자동 GUI 검사로 검증했습니다. 사용자 새 프로젝트의 시작 확인은 미리 저장하지 않았습니다.

## 실제 영상 확인

0928의 두 원판 영상 네 편을 개발 검증에 사용했습니다. 아래 시작 프레임은 개발자가 시험용으로 고른 값이며, 사용자의 승인값이 아닙니다. 새 프로젝트에서는 사용자가 다시 선택해야 합니다. 프레임 번호는 0부터 시작합니다.

| 영상 끝번호 | 시험 시작 | 분석 프레임 수 | 위치 관측 행 | 속도/각속도 행 | 최종 사건 분류 |
|---|---:|---:|---:|---:|---|
| 200141 | 120 | 207 | 414 | 각각 394 | 고립 2체 충돌 후보 |
| 200247 | 112 | 215 | 430 | 각각 418 | 고립 2체 충돌 후보 |
| 200256 | 190 | 313 | 626 | 각각 612 | 비접촉 통과, 반발계수 제외 |
| 200228 | 36 | 217 | 434 | 각각 420 | 고립 2체 충돌 후보 |

네 편 모두 칩 수 2개를 제안했고 선택한 구간의 위치 관측이 저장되었습니다. 관측 행에는 흐림·추가 원 후보 등 검토 경고가 있을 수 있습니다. **관측 누락이 없다는 뜻과 중심·각도가 정확하다는 뜻은 다릅니다.** 충돌 후보 또한 사람의 검토와 피팅 조건 검사를 통과해야 합니다.

격자 보정의 내부 보류점 오차는 순서대로 약 0.532, 0.526, 0.216, 0.505 mm였습니다. 이는 검출한 격자와 추정 변환 사이의 일관성 수치입니다. 독립 기준자를 이용한 검증, 칩 중심 정확도, 표식 각도 정확도 또는 전체 물리 좌표의 절대 정확도와 같지 않습니다. 보정 상태는 잠정(provisional)입니다.

실제 영상을 다시 디코딩해 관측을 생성한 뒤, 비접촉 분류와 품질 경고 전달의 최종 수정은 저장된 동일 원본 관측에 재적용했습니다. 원래 실행 manifest를 덮어쓰지 않았으며 `v35_derivation_audit.json`에 최종 계산 코드 해시를 남겼습니다. 최종 요약은 `final_real_summary.json`, 격자 시도 기록은 `real_grid_checks.json`입니다. 이 자료들은 버전 개발에 사용했으므로 논문의 완전히 새로운 검증 영상으로 취급하지 마세요.

## 물리 해석의 범위

바닥 마찰계수는 연속 자유운동의 위치·각도로 추정합니다. 그 값을 고정하고 충돌 직전·직후 관측 구간을 Farkas 모델로 맞춰 동일 충돌 시각의 상태를 구합니다. 그 상태는 **Farkas 모델에 조건부인 추정**입니다. 관측값과 모델 환산값을 섞어 모델의 참을 주장하면 안 됩니다.

학습은 계수 측정용 영상만 읽고, 고정 검증은 저장한 계수 해시와 원본 영상 중복을 검사합니다. 자유운동 검증의 앞 12개 관측은 초기 상태 추정에 사용되므로 예측 오차 평가에서 제외합니다. 충돌 검증은 관측한 충돌 직전 상태에서의 조건부 예측입니다. 전체 실험을 최초 상태 하나로 끝까지 예측하는 완전한 연속 검증과 구별합니다.

이번 배포 검증만으로 실제 마찰계수·IFR 접선 계수의 확정값이나 신뢰구간을 인증하지 않습니다. 바닥 마찰·법선 반발만 추정되고 접선 계수는 보류되는 결과가 가능합니다. 표시되는 잠정 계수는 연구 최종값으로 사용하기 전에 독립 영상 검증과 촬영·보정 불확실성 검토가 필요합니다.

## 남아 있는 제한

- 삼성 영상 전체가 1/8배속이라는 사용자 촬영 조건으로 PTS를 8로 나눕니다. 일부만 슬로모션이거나 편집된 파일, 중복 프레임의 독립 시간 검증은 별도 필요합니다.
- 시작은 영상 전체에 공통입니다. 원판별 서로 다른 발사 시점의 자동/개별 선택은 제공하지 않습니다.
- 긴 격자 방향 판별은 수직에 가까운 촬영을 전제로 합니다. 큰 카메라 기울기에서는 영상상 긴 방향이 실제 긴 방향이라는 보장이 없습니다.
- 흐림, 가림, 원판 들림, 표식 소실은 프로그램만으로 원래 정보를 복원할 수 없습니다. 해당 구간을 검토·제외해야 합니다.
- 롤링셔터 보정은 사용자 요청대로 하지 않습니다. 잔여 오차 요인으로 남습니다.
- 이번 새 실제 영상 회귀 검증은 2개 원판 네 편입니다. 3개 이상과 동시 접촉의 실험적 정확도는 검증하지 않았습니다. 동시 다중 충돌을 고립 2체 IFR 계수 학습에 넣지 않습니다.
- 진행률은 처리 단계와 프레임의 가중 진행률입니다. 남은 시간의 정확한 추정값은 아닙니다.
- Python 실행 패키지이며 독립 EXE는 아닙니다. 이 노트북에는 실행 환경을 준비했고 다른 컴퓨터는 SETUP이 필요합니다.

## 자료 정리

기본 연구 폴더를 논문 / 시뮬레이션 / 실제 실험 영상 / 실험 데이터 / 이론 / AI 지시문 및 안내문 / 보관으로 정리했습니다. 기존 결과와 프로그램은 삭제하지 않고 보관으로 이동했습니다. 원문 논문·보정판 및 원본 영상 사본의 SHA256 검증 기록을 보관했습니다. E: USB의 원본은 변경하지 않았습니다.

Google Drive 폴더 목록은 확인했으나 추가 영상 한 편의 다운로드가 접근 오류(403)로 실패했습니다. 해당 추가 영상은 분석했다고 주장하지 않으며, 위 검증은 접근 가능한 로컬 원본에 근거합니다.
