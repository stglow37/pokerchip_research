# 계수를 구할 영상과 고정 계수로 검증할 영상 나누기

## 사용 순서

1. 먼저 모든 영상을 일반 분석해 위치·회전·충돌 자료를 저장합니다.
2. **저장된 결과 → ① 영상 용도 나누기**를 누릅니다.
3. 각 영상에 **계수 구하기용 / 고정 계수 검증용 / 이번 계수 연구에서 제외** 중 하나를 지정합니다. 기본값은 제외입니다. 영상 전체를 단위로 분리하며 같은 영상을 양쪽에 중복 지정할 수 없습니다.
4. 충돌을 피팅에 쓰려면 원본과 검출 그림에서 칩 번호·충돌 전후 추적을 확인한 뒤 해당 영상의 **충돌 장면 확인**을 체크합니다. 자유운동 피팅에는 이 확인이 필요하지 않습니다. 영상 검토 체크만으로 부족한 각속도·접촉 기하가 복구되지는 않습니다.
5. **② 측정용 영상으로 계수 구하기**를 누릅니다. 여러 측정용 영상에서 공통 계수를 구합니다. 영상마다 초기 상태는 다르게 둡니다.
6. 저장된 계수를 확인하고 **③ 저장 계수로 검증 영상 비교**를 누릅니다. 검증 영상에는 계수를 고정하며 계수 피팅 함수를 호출하지 않습니다. 초기 위치·속도 등의 상태만 처음 12프레임에서 추정합니다.

## 자동 피팅되는 것

| 물리량 | 사용 자료와 조건 |
|---|---|
| 바닥 마찰계수 μ_b | 직접 관측한 연속 자유운동의 위치·회전. 여러 영상에 공통 μ, 구간별 초기 상태. 충분한 이동·회전·국소 식별성이 필요 |
| 법선 반발계수 e_n | 검토된 고립 2체 충돌의 법선 상대속도. 0~1 범위의 robust 최소제곱. 충돌 하나에서도 잠정 피팅 가능 |
| IFR 접선 반발계수 e_t, 충돌 마찰 μ_c | 서로 다른 조건의 검토된 충돌 3개 이상, 전후 각속도 필요. 오차가 있는 입력 상태를 함께 조정하는 기존 IFR 피팅 사용. 국소 식별성·경계·수동 충돌 에너지 조건 통과 시에만 고정 적용 |

‘3개’는 최소 실행 조건일 뿐 신뢰성 기준이 아닙니다. 같은 입사 조건의 충돌을 많이 모아도 e_t와 μ_c를 분리하지 못할 수 있습니다. 식별되지 않은 값은 `constants.json`의 진단에만 남기며 고정 적용 계수 목록에 넣지 않습니다. 판별 결과가 나쁘면 다른 충돌 속도·입사각·회전 조합이 필요합니다.

정상적으로 계산된 일부 계수만 있어도 저장됩니다. μ_b만 구해졌으면 자유운동 검증이 가능하고, e_n만 구해졌으면 충돌 후 법선 상대속도만 비교합니다. 전체 IFR 속도·회전 예측에는 e_n, e_t, μ_c 모두가 필요합니다. 빈 계수를 0이나 임의 기본값으로 채우지 않습니다.

## 저장 파일

`results/계수_측정/상수기록번호/`:

- `측정한_계수.csv`: 한국어 계수명, 값, 계산 가능 여부.
- `constants.json`: 계수, 피팅 영상 원본 해시, 구간, 초기 상태, 사용 모델, 진단, 코드 해시, 계수 해시. 매번 새 기록으로 저장합니다.
- `읽어주세요.txt`: 결과의 의미.

`results/고정계수_검증/검증기록번호/`:

- `고정계수_검증요약.csv`: 영상별 위치·각도 RMSE, 충돌 속도·각속도 오차, 법선 상대속도 오차.
- `고정계수_예측비교.csv`: 평가 프레임별 실제 관측과 고정 계수 예측.
- 영상·칩별 비교 그림.
- `validation.json`: 적용한 계수, 계수 해시, 검증 원본, 초기화 프레임, 평가 프레임, 건너뛴 충돌 사유.

계수 해시를 실행 전후 기록하고, 저장된 계수가 바뀌면 적용을 거부합니다. 측정에 쓴 원본을 이름만 바꿔 검증 영상으로 넣어도 원본 해시가 같으면 거부합니다. 마지막으로 피팅한 계수 파일이 프로젝트에 연결됩니다. 재피팅하면 새 파일이 연결되며 과거 파일은 유지됩니다. 검증 기록에는 적용한 계수 기록번호가 남습니다.

## 초기 조건과 평가 범위

검증 영상의 처음 12개 연속 관측으로 초기 위치·속도·각도·각속도를 구합니다. 이후 프레임을 참조하는 평활 속도를 쓰지 않고, 그 12개의 직접 위치·각도만 사용합니다. 단순 직선에서 끝내면 감속 때문에 구간 끝의 속도를 과대평가하므로, **μ는 고정한 채 초기 상태 6성분만** Farkas 모델로 추정합니다. 12개 프레임은 평가 RMSE에서 제외합니다. 그 다음부터는 고정 μ로 자유운동을 예측합니다. 충돌은 관측한 충돌 직전 상태에서 고정 IFR 계수로 직후 상태를 예측합니다.

따라서 현재 원클릭 검증은 **초기 상태를 관측한 자유운동 예측**과 **충돌 직전 상태를 관측한 충돌 직후 예측**입니다. 처음부터 마지막까지 한 번도 관측으로 재시작하지 않는 Farkas→IFR→Farkas 전체 연속 예측 검증과는 구별해야 합니다. 연속 시뮬레이터는 고급 기능에 있지만 이번 버튼의 오차를 그 전체 검증 결과로 해석하면 안 됩니다.

## 연구 해석

현재 자동 보정·시간 상태가 provisional/declared여도 탐색 피팅은 허용하되 결과에 잠정 상태를 명시합니다. 이를 검증됨으로 자동 승격하지 않습니다. 위치 0.5mm·각도 0.035rad 및 법선 속도 0.03m/s는 탐색 가중치이며 계측으로 확보한 표준편차가 아닙니다. 출력된 국소 공분산은 실제 95% 신뢰구간이 아닙니다. 반복 실험과 공통 보정·시간 오차를 포함한 신뢰구간은 기존 고급 bootstrap 기능으로 별도 구성해야 합니다.

같은 촬영일의 영상끼리는 보정 오차를 공유합니다. 우선 영상 단위로 나누되 최종 연구에서는 다른 촬영 세션도 남겨두는 것이 좋습니다. 검증 영상을 보면서 검출·피팅 방법을 계속 조정했다면 그 영상은 개발 자료가 되므로, 최종 검증 영상은 새로 따로 확보하세요. 이번 네 영상은 개발에 사용했으므로 기능 시험 결과를 독립 연구 검증 성적으로 부르지 않습니다.
