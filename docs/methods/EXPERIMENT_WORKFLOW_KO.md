# 실제 실험 준비와 실행

## 1. 촬영과 시간 기준

편집·메신저 재인코딩 전 원본을 보존하고 촬영일/session, 기종, 앱·모드·해상도·줌·안정화·노출·slow 편집/내보내기 이력을 기록합니다. 목표는 FHD native 240fps입니다. 현재 제공 두 과거 영상은 약60fps 재생 메타데이터이며 이를 native240 촬영 근거로 사용하지 않습니다.

알려진 주기의 독립 광원/타이머로 frame PTS→물리 시각을 확인합니다. 단순 조명 깜빡임을 정확한 기준으로 가정하지 않습니다. 촬영 PTS가 이미 보존되면 slow factor=1, 재생이 느려졌으면 확인된 구간별 factor를 사용합니다. `t=t_start+(p−p_start)/slow_factor`이며 구간 경계는 연속이어야 합니다. 중복/보간 프레임은 `frame_types`에 근거와 함께 지정합니다. 이미지가 같다는 이유만으로 정지 프레임을 중복이라고 삭제하지 않습니다.

## 2. 칩 물성과 표식

| ID | rim | inner |
|---|---|---|
| chip_1 | red | blue |
| chip_2 | blue | yellow |
| chip_3 | green | red |

inner 지름은 설계상 3mm, 대략 0.5R지만 실제 반경비와 상대각은 영상에서 학습합니다. 명목 반지름 20mm는 실측 전 pending입니다. 칩별 질량·반지름·두께를 측정하고 반복 측정 sigma를 기록합니다. I는 별도 측정하거나 균질 원판 근사 선택을 명시합니다. 전면 원형 균일압력 가정은 질량분포까지 실측했다는 뜻이 아닙니다.

고정 칩을 여러 시야 위치·방향에 놓아 중심·각도 반복성을 측정합니다. 3mm 스티커의 픽셀 크기와 실제 이동 중 blur를 확인합니다. 같은 색이라도 rim/inner radial band, 칩 조합, 상대각으로 구별합니다. 조명이 달라지면 색 학습도 갱신합니다.

## 3. 카메라와 평면

실험과 같은 촬영 모드에서 다양한 보드 위치·크기·기울기의 ChArUco 영상을 얻습니다. 보드 square/marker 길이를 실측합니다. 학습하지 않은 pose/코너의 잔차를 확인합니다. 바닥 격자는 x/y 간격을 따로 측정하고 원점·y 위쪽 축을 정합니다. fit에 쓰지 않은 점과 길이로 world scale을 확인합니다.

카메라는 고정합니다. drift 경고가 생기면 원인을 확인하고 별도 보정 구간으로 나눕니다. 매 프레임 H를 임의 갱신하여 실제 운동을 상쇄하지 않습니다. 두께와 K/pose가 있으면 윗면 ray-plane 보정을 적용합니다. 두께 또는 pose가 없으면 높이 보정이 불가능한 상태를 유지합니다.

## 4. 실험군과 보류 세션

1. 단일 칩: 여러 초기 속도·spin으로 자유운동을 반복합니다. 발사기/손이 접촉한 구간은 제외합니다. μ_b를 추정하고 압력 가정·직선 이동·정지 특성을 확인합니다.
2. 정상 충돌: 다양한 정상 접근 속도에서 e_n을 추정합니다. grazing이나 정상속도≈0의 ratio는 피합니다.
3. 접선 충돌: 넓은 c/J_n, 양/음 접선 방향, 양/음 초기 spin과 칩 조합을 포함해 e_t/μ_c를 구분합니다. sticking-only에서는 μ_c 하한만 결정됩니다.
4. 3칩: 시간상 분리된 순차 2체 충돌로 먼저 검증합니다. 동시 접촉·겹침·뜀·쌓임은 별도 분류합니다.
5. 영상 또는 날짜/session 전체를 학습/보류로 나눕니다. 같은 영상 프레임을 임의 분할한 검증을 독립 holdout으로 세지 않습니다.

## 5. 결과 검토

자동 후보는 검토를 거쳐 승인합니다. 중심/표식/ID가 불확실한 프레임을 숨기지 않고 제외 이유를 남깁니다. 물리 solver가 그럴듯하게 채운 좌표를 관측으로 바꾸지 않습니다. 시간·기하·각도 alias가 검증되지 않은 결과는 frame-index 관측까지만 사용합니다.

전체 대상 chip-frame 수를 분모로 유효률을 계산하고, 독립 수동 정답을 확보했다면 검출 recall·ID switch·중심/각도 오차도 별도로 계산합니다. 프로그램의 관측 행 비율은 정답 recall이 아닙니다. 계수·CI·holdout 단위별 오차와 모델의 적용 범위를 함께 보고합니다.

## 실제 자료 도착 후 완료할 검증

- native240 독립 시간 검증과 variable-rate/slow 구간 대조.
- 새 3칩 표식의 정적·동적 반복성, 표식 가림·재등장·ID switch 검증.
- 실제 렌즈/평면/두께 보정의 독립 길이·각도·위치 오차.
- 측정된 물성으로 단일칩/정상/접선 계수 반복성과 session holdout 예측.
- 실제 FHD240 장시간 영상의 처리시간·peak RAM, 목표32GB 노트북 재현.

이 항목들은 추가 개발 허가를 요구하는 목록이 아니라, 아직 제공되지 않은 실험 자료로 수행해야 하는 연구 검증입니다.
