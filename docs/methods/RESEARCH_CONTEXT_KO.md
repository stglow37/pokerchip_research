# 연구 맥락: 회전 원판의 자유운동과 두 원판 충돌

## 연구 질문

이 저장소는 평면 위에서 미끄러지고 회전하는 포커칩을 영상으로 계측하고 다음 질문을 연구하기 위한 도구다.

1. 바닥과의 분포 마찰이 병진 속도와 회전에 어떤 변화를 만드는가?
2. 두 원판의 충돌 전 상태로부터 충돌 후 병진·회전 상태를 설명할 수 있는가?
3. 바닥 마찰계수, 법선 반발계수, 접선 반발계수와 충돌 마찰계수를 어떤 자료에서 식별할 수 있는가?
4. 영상 계측 오차와 모델 오차를 숨기지 않고 어떤 결론까지 재현 가능하게 주장할 수 있는가?

현재 목표는 모든 영상에서 모든 계수를 강제로 출력하는 것이 아니다. 측정 가능한 값에는 근거·단위·불확실성·적용 범위를 남기고, 측정 불가능한 값에는 보류 이유를 남기는 것이다.

## 증거의 네 층

### 1. 직접 관측

- 원본 프레임과 presentation timestamp
- 원판 중심·반지름·경계 표본
- 색 표식과 감싼 각도
- 사용자가 확인한 중심, ID, 각도, 사건 상태, 제외 구간

직접 관측도 검출기와 보정에 조건부일 수 있다. `observed`는 독립 정답과 일치한다는 뜻이 아니다.

### 2. 파생량

- 물리 시간과 world 좌표
- 속도·가속도·각속도
- 연속 각도
- 충돌 후보와 전후 한쪽 적합 상태
- 품질 상태와 조건부 공분산

파생량은 시간·기하·연속 구간·사건 장벽에 의존한다. 결측이나 충돌을 가로질러 평활화하지 않는다.

### 3. 모델 추정과 예측

- Farkas 분포 마찰 모델의 자유운동 예측과 `mu_bottom`
- 위치·속도 기반 법선 반발계수 `e_normal`
- 회전 자료를 요구하는 IFR의 `e_tangential`, `mu_collision`
- 고정 계수를 사용한 조건부 holdout 또는 full-forward 예측

모델 적합 성공은 실제 재료 상수의 정확도나 모델의 외적 타당성을 자동으로 보장하지 않는다.

### 4. 독립 검증

- 학습에 쓰지 않은 원본 영상과 가능하면 다른 session
- 독립 시간 기준과 독립 길이·보정 holdout
- 사람이 만든 독립 중심·ID·사건 정답
- 계수를 다시 맞추지 않은 고정 예측

현재 자동 시험은 소프트웨어 일관성과 합성 정답 복원을 강하게 검사하지만, 새로운 독립 실제 영상에 대한 최종 연구 검증은 남아 있다.

## 모델 역할

Farkas 모델은 원판 전면의 균일 압력과 Coulomb 미끄럼 마찰을 가정해 병진과 회전 감속을 연결한다. IFR 모델은 두 원판 충돌에서 법선·접선 impulse와 두 원판의 spin을 연결한다. 정확한 식, 부호, 제한 범위와 문헌 인쇄식에서 달리 채택한 부분은 [MODEL_DECISIONS_KO.md](MODEL_DECISIONS_KO.md)가 정본이다.

추정 순서는 다음과 같이 분리한다.

1. 사건에서 떨어진 단일 원판 자유운동으로 `mu_bottom`
2. 검토된 고립 2체 충돌의 중심 속도로 `e_normal`
3. 회전까지 유효한 여러 충돌로 `e_tangential`과 `mu_collision`
4. 학습에 쓰지 않은 영상에서 고정 계수 검증

회전 결측은 IFR를 보류하지만 위치 기반 `e_normal`까지 차단하지 않는다. IFR 단계는 별도 법선 단계의 값을 고정하여 다시 덮어쓰지 않는다.

## 현재 가정과 비지원 범위

- 내부 단위는 SI, world y는 위쪽, 각도와 각속도는 반시계 양수다.
- 원판은 평면 강체이며 기본 관성은 명시적으로 선택한 균질 원판 근사 또는 실측값이다.
- 순간 충돌 동안 바닥 impulse는 기본 충돌 모델에서 무시한다.
- 진짜 동시 다체 접촉, 지속 접촉, 적층, 3차원 뜀, rolling 마찰, 환형 압력과 속도 의존 마찰은 확정 모델이 아니다.
- 화면 이탈, 손·발사기 재접촉, 심한 가림은 자동으로 그럴듯한 물리 상태를 만들어 채우지 않는다.
- 시간 또는 기하가 미확정이면 SI 속도·계수 산출을 보류할 수 있다.
