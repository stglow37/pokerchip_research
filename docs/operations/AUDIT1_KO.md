# 6.0.0+audit1 연구용 개선본

이 폴더는 v6.0.0 소스에서 만든 별도 로컬 개선본이다. 사용자 원본 ZIP, 영상, 기존 연구 저장소를 수정하지 않았다. 공식 릴리스나 검증된 새 물리 법칙으로 취급하지 않는다.

변경은 두 가지다. `measurement/scene.py`는 초반 격자가 가려졌을 때 뒤쪽 프레임에서 같은 기준으로 평면 보정을 재시도한다. `models/contact_field.py`는 균일한 원형 접촉면 위에 음수가 아닌 비균일 마찰 세기를 둔 자유운동 후보 모델을 제공한다. Farkas/IFR 기본 경로와 기존 저장 형식은 유지한다.

후보 모델의 상태 순서는 [x,y,vx,vy,theta,omega], SI 단위, 반시계 회전 양수다. 계수는 [mu0,mux,muy], 조건은 mu0>=sqrt(mux²+muy²)이다. `acceleration_basis`, `acceleration`, `simulate`는 기존 GUI 버튼과 분리된 연구 API다. 회전 증가를 만들 수 있어도 실험 원인을 식별했다는 뜻은 아니다. 충돌이나 들림은 이 모듈이 처리하지 않는다.

원판은 반지름 0.020m, 질량 0.012kg, 관성모멘트 0.5mR²를 기본값으로 사용했다. 모든 준비물이 같다는 사용자 확인은 반영했지만 독립 길이·시간·관성의 오차 크기는 제공되지 않았다. 영상 불확도와 공통 체계 오차를 구별해야 한다.

전체 영상 인벤토리, 영상별 사용 구간, 계수와 예측 검증은 이 코드 폴더 상위의 분석 산출물에 저장한다. 본 소스 ZIP에는 원본 영상을 포함하지 않는다. 상세 결정은 ADR-009와 ADR-010, 실행 결과는 `validation/test-records/audit1/`을 확인한다.

별도 분석 작업에는 손·발사기 색상 근접 구간 제외, 원판 전체의 바닥 내부 여부, 시간 공백을 넘지 않는 미분, 영상 단위 재표집, 충돌 직전 상태의 관측 오차를 포함한 적합, 계수 고정 후 예측 비교를 추가했다. 이들은 분석 묶음의 재현 스크립트이며 GUI에 자동 통합된 기능이 아니다. 색상 근접 검사는 보수적 제외 보조수단으로, 표시되지 않은 구간이 외력 없이 움직였음을 독립적으로 인증하지 않는다.

비균일 모델은 자유운동만 처리한다. 여러 접촉이 겹치는 충돌을 임의의 이진 충돌 순서로 해결하거나 수동 승인된 사건으로 바꾸지 않는다. 자동 측정 성공, 계산 완주, 관측 일치, 사람 승인 상태를 각각 구분한다.
