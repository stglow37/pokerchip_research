# 포커칩 연구실 v4.5 사용 설명서

## 먼저 알아둘 것

이 프로그램은 **영상의 관측값**, **물리계수 피팅**, **고정 계수로 다른 영상 예측**을 구분합니다. 파일 저장 완료, 원 검출 성공, 물리 모델 검증 성공은 서로 다릅니다. 초록색 원이나 진행률 100%가 실험 정확도 100%를 뜻하지 않습니다.

기본 실험은 검정 포커칩, 가장자리의 비대칭 색 표시, 내부 스티커입니다. 질량은 12 g, 지름은 40 mm, 관성모멘트는 균질 원판 `I = mR²/2` 근사입니다. 모두 촬영·칩 설정에서 변경할 수 있습니다. 칩 전체가 유색인 실험을 전제로 하지 않습니다.

삼성 원본 슬로모션 전체가 1/8배속인 경우 파일 재생시간을 8로 나눕니다. 30 fps 파일의 인접 프레임은 실제 약 1/240초입니다. **240으로 계산한 시간을 또 8로 나누지 않습니다.** 원본에 정상 속도 구간·반복 프레임·편집 구간이 섞이면 구간별 시간 설정과 원본 확인이 필요합니다. 롤링셔터 보정은 하지 않습니다.

## 실행

1. 처음 받은 컴퓨터에서는 Python 3.14를 설치한 상태로 `SETUP.cmd`를 한 번 실행합니다. 인터넷에서 필요한 라이브러리를 설치하므로 시간이 걸릴 수 있습니다.
2. 이후 `RUN.cmd`를 실행합니다. 이 컴퓨터에 별도로 연결한 `runtime.local.json`이 있으면 기존 검증 환경을 사용합니다. 이 파일은 다른 컴퓨터로 복사하지 마세요.
3. VS Code에서는 이 `pokerchip_research` 폴더를 열고 `.venv`의 인터프리터를 선택합니다. 터미널 실행은 `python run_gui.py`입니다. 상위 압축 해제 폴더에서 설치 명령을 실행하지 마세요.

이번 검수 환경은 Windows x64 / Python 3.14.6입니다. 설치한 3.14를 지우거나 3.12로 바꿀 필요가 없습니다. 정확한 검수 라이브러리 버전은 `requirements-v45-tested.txt`입니다. Python 없는 독립 EXE의 빌드·별도 PC 검증을 마친 배포판이라는 뜻은 아닙니다.

## 1. 영상 넣기

- 새 실험 폴더를 정합니다. 원본 영상 폴더와 결과 폴더를 분리하면 편합니다.
- 보정 영상과 실험 영상들을 넣습니다. 여러 실험 영상의 드래그앤드롭을 지원합니다.
- 보정판 규격은 11 × 8칸, 15 mm 격자, 11 mm 마커, DICT_4X4_50입니다.
- 바닥 격자 한 칸은 짧은 방향 40.5/18 cm = 22.5 mm, 긴 방향 43/18 cm ≈ 23.8889 mm입니다. 큰 점 9개는 사용하지 않습니다.
- 보정판을 마지막에 실제 실험 바닥에 평평하게 놓았을 때만 해당 확인란을 체크합니다. 허공에 든 판의 평면을 바닥으로 승인하지 마세요.
- 영상 목록을 더블클릭하거나 `시작 프레임 선택 · 필수`를 누릅니다.

## 2. 시작 프레임은 사람이 지정

손이나 고무줄에서 완전히 벗어난 뒤 칩이 보이는 장면을 선택합니다. 프레임 번호는 0부터 시작합니다. 번호를 입력하고 Enter를 누르거나 ±1 버튼으로 한 프레임씩 이동합니다. 표시할 프레임을 읽는 동안에는 저장이 허용되지 않습니다.

`전체화면 (F11)`으로 크게 보고, Esc로 원래 창으로 돌아옵니다. 일반 창에서 Esc를 누르면 선택을 취소합니다. 오른쪽 마우스 드래그로 이동하고 휠 또는 확대 버튼으로 확대합니다. 가운데 마우스 버튼은 필요하지 않습니다.

화면의 장면을 확인한 뒤 접촉 종료 확인란을 체크하고 `이 프레임부터 분석`을 누릅니다. **프로그램이 대신 시작을 승인하지 않습니다.** 파일이 달라지면 이전 승인을 재사용할 수 없습니다.

영상 전체를 일찍 끝내야 할 때에는 종료 제한을 지정합니다. 원판마다 나가는 시점이 다르면 전체 영상 종료 대신 아래의 칩별 종료를 사용하세요.

## 3. 측정 시작과 진행 표시

`측정 시작 · 선택 프레임부터 자동 저장`을 누릅니다. 영상의 격자를 확인하고 개수를 제안한 다음 중심·표식·운동학을 계산하여 저장합니다.

영상 처리에는 현재 몇 번째 영상인지, 현재 영상 진행률, 전체 단계 진행률이 표시됩니다. 이는 처리 단계 기준이고 남은 시간의 정확한 예측이 아닙니다. 피팅에서는 단계 진행률과 경과 시간·모델 평가 횟수를 표시합니다. 비선형 최적화 도중에는 수렴까지 남은 횟수를 알 수 없어 움직이는 막대를 씁니다. 가짜 수렴 퍼센트를 표시하지 않습니다.

`현재 작업 중단`은 계산의 안전한 경계에서 취소합니다. 버튼을 누른 순간 진행 중인 수치 적분 하나가 즉시 끝나는 것은 아닙니다. 중단·오류는 결과 폴더의 작업기록에 남습니다. 계산 중 설정이나 수정 대상을 바꾸지 마세요.

## 4. 이상한 부분 확인

저장된 결과 표에서 영상을 더블클릭하면 검토 화면이 열립니다. 기본 그래프는 바닥의 2차원 궤적입니다. 보정이 있으면 cm, 없으면 px입니다. **px도 x·y 두 좌표를 가진 2차원 좌표이며 단위만 픽셀인 것입니다.**

시간 그래프를 선택하면 x(t)·y(t), 회전각(rad), 각속도(rad/s)를 봅니다. 가림·이탈 구간을 직선으로 연결하여 실제 관측처럼 표현하지 않습니다.

검토 영상에서도 전체화면을 열 수 있습니다. 전체화면 안에서 칩·점 도구를 선택하고 프레임을 이동할 수 있습니다. 닫으면 원래 검토창으로 돌아갑니다.

### 원 중심과 표식

- 초록 원: 중심과 외곽선 측정.
- 노랑 십자·방향선: 가장자리 표식.
- 파랑 십자·방향선: 안쪽 스티커.
- `?`: 후보가 모호함. 방향선을 표시했다고 믿을 만한 회전 측정이라는 뜻은 아닙니다.
- `표식 미검출`, `회전 미측정`: 위치가 있어도 각속도까지 계산할 근거가 부족합니다.

점 도구의 의미는 다음과 같습니다.

| 도구 | 하는 일 |
|---|---|
| 확대·조회 | 영상을 이동하고 확대하여 확인 |
| 중심 보정 클릭 | 현재 선택 칩의 현재 프레임 중심을 수정. 관측이 없으면 수동 추가 가능 |
| 가장자리 색 표시 클릭 | 클릭 위치를 임시로 기억 |
| 안쪽 스티커 클릭 | 스티커 위치를 임시로 기억 |
| 클릭한 표식으로 이 장면 각도 수정 | 가장자리 클릭을 현재 한 프레임의 각도 보정으로 저장 |
| 클릭한 색을 다음 추적에 사용 | 색·기하 기준을 저장하고 다음 재분석에 사용 |
| 격자 대응점 클릭 | 실제 바닥 좌표에 대응하는 격자 교차점을 입력 |

중심을 바꾸면 방향 벡터도 바뀝니다. 재분석 시 유효한 원시 가장자리 좌표가 있으면 각도를 다시 계산하고, 근거가 없으면 옛 각도를 지웁니다. 칩 중앙에 정확히 붙은 점은 회전 방향을 알려주지 못하므로 안쪽 스티커를 억지로 회전각으로 사용하지 않습니다.

클릭 수정은 이력으로 저장됩니다. `보정 반영 재분석`을 눌러 속도·충돌·피팅 입력을 갱신하세요. 수정 전 결과는 덮어쓰지 않습니다. 다른 프레임이나 칩으로 이동하면 표식 임시 선택을 다시 해야 합니다.

### 칩별 정지와 이탈

선택 칩의 해당 장면에서 `이 칩의 정지·이탈 지정`을 누릅니다.

| 상황 | 선택과 의미 |
|---|---|
| 이동·회전 모두 정지 | 완전히 멈춤. 이후 관측과 재충돌을 삭제하지 않음 |
| 중심은 멈췄지만 계속 회전 | 이동만 멈춤. 회전 자료를 유지 |
| 화면 밖으로 나감 | 화면 이탈 직전. 현재 프레임까지 포함하고 다음부터 관측 대상에서 제외 |
| 바둑판 밖 다른 바닥으로 이동 | 바닥 이탈 직전. 이후 위치를 저장하되 공통 바닥 마찰 피팅에서 제외 |
| 다시 들어옴 | 재진입 첫 장면. 사라진 구간을 가로질러 미분하지 않음 |
| 여러 유효 구간 | 구간 표 편집. 시작·끝과 피팅 사용 여부를 직접 지정 |

정지 확인은 측정값을 0으로 덮어쓰는 기능이 아닙니다. 화면 이탈 이후를 검출 실패로 세지 않도록 관측 가능 범위를 별도로 저장합니다.

### 충돌 경계

충돌 목록의 전후 프레임은 후보 탐색 범위와 다릅니다. `충돌 전후 프레임 지정`에서 왼쪽에 마지막 충돌 전 장면, 오른쪽에 첫 충돌 후 장면을 놓고 저장합니다. 예를 들어 31→32라면 31과 32를 모두 유효 표본으로 보존하고 그 사이에서 미분 창을 끊습니다.

자동으로 좁힌 경계도 제안입니다. 흐릿한 장면을 억지로 사용하지 말고 더 선명한 전후 프레임을 고르세요. 전후 지정 후 재분석하고 칩 번호·법선·전후 추적을 확인하여 충돌을 건별로 승인합니다.

`실제 충돌이지만 계수 계산에서 제외`는 충돌 장벽을 유지합니다. `충돌하지 않고 지나감`일 때만 장벽을 없앱니다. 이 둘을 혼동하면 속도 미분이 충돌을 가로질러 반발계수가 틀어집니다.

## 5. 거리 보정 확인

렌즈 내부 보정과 실험 바닥의 거리 변환은 별개입니다. 카메라 자세·줌·초점·해상도가 바뀌면 보정을 그대로 신뢰할 수 없습니다. 각 영상의 격자선으로 바닥 평면을 다시 검사합니다.

자동 거리 변환에 문제가 있으면 검토 화면에서 넓게 떨어진 격자 교차점을 클릭하고 칸 번호를 입력합니다. 임의의 한 교차점을 (0,0)으로 잡습니다. 같은 줄을 따라 가로 번호를, 다른 방향으로 세로 번호를 늘리세요. 마지막 두 점은 변환 계산에 넣지 않는 검사점입니다. 총 6점 이상을 지정하되 바닥 전체에 넓게 분포시키세요.

실제 가로 번호 방향이 긴 변인지 짧은 변인지 확인합니다. **원근 때문에 화면에서 길게 보이는 방향이 반드시 실제 긴 방향은 아닙니다.** 자동 배정은 초기 제안이고, 수동 방향 확인이 최종 판단입니다. 두 방향의 원판 지름·독립 자 길이로 확인하면 더 좋습니다. 이 영상에서 저장한 수동 평면은 자동 재분석이 몰래 교체하지 않습니다.

검사점 잔차가 작아도 격자 자체 실측 오차·칩 높이·렌즈 변화까지 검증한 것은 아닙니다. 논문용 정확도는 별도 실측 기준으로 확인하세요.

## 6. 물리계수 구하기와 검증

1. `영상 용도 나누기`에서 계수 구하기용과 고정 계수 검증용을 나눕니다.
2. `계수별 준비 상태 확인`에서 자유운동 구간과 법선/IFR 입력 자격을 확인합니다. 표시되는 구간은 실제 선택한 프레임입니다.
3. `측정용 영상으로 계수 구하기`를 실행합니다.
4. `저장한 계수·미산출 이유 보기`에서 각 계수를 별도로 확인합니다.
5. `저장 계수로 검증 영상 비교`를 실행합니다. 검증에서는 물리계수를 다시 피팅하지 않습니다.

바닥 마찰은 회전·병진이 결합된 Farkas 자유운동으로 구합니다. 중심 위치만으로 정상 방향 속도를 얻을 수 있는 충돌은 회전 자료가 부족해도 법선 반발계수 후보를 만들 수 있습니다. 접선 반발과 칩 충돌 마찰을 분리하려면 충돌 양쪽 칩의 회전까지 측정되고 서로 다른 조건의 충돌들이 있어야 합니다. 최소 사건 수를 채웠다는 사실만으로 두 계수가 식별되지는 않습니다.

계수가 경계값에 붙거나 서로 구별되지 않거나 충돌 에너지가 증가하는 비물리 해이면 고정 적용을 보류합니다. 최적화 성공과 연구 신뢰성을 분리합니다. 미산출 값은 0이 아니라 빈 값과 이유로 기록합니다.

저장된 검증은 자유운동에서는 첫 12프레임으로 초기 상태를 추정한 뒤 나머지 장면을 예측합니다. 충돌에서는 관측된 충돌 전 상태에서 직후를 예측합니다. 이는 조건부 검증이고, 처음부터 전체 다중 충돌을 모두 예측한 검증과 다릅니다. 같은 날의 영상은 공통 보정 오차를 공유합니다. 반복해서 개발에 쓴 영상은 새 독립 검증 자료가 아닙니다.

상세 피팅 화면은 bootstrap과 세션 단위 분할을 지원합니다. 반복 수가 적거나 독립 세션이 부족하면 CI를 확정하지 마세요. 기본 간편 계수값은 아직 보정된 절대 신뢰구간을 가진 물성치가 아닙니다.

## 모델 범위

- Farkas는 평면에 전체 접촉하는 원판의 균일 압력·등방 마찰 근사입니다. 기울어짐, 들뜸, 바닥 바뀜을 같은 계수에 섞지 마세요.
- IFR에는 원문 무초기회전 범위와 초기 회전을 허용한 접촉 일관성 확장 모델을 구별하여 기록합니다. 기본 회전 충돌 분기는 수학적 확장으로, 그 자체가 논문의 실험 검증을 그대로 물려받지는 않습니다.
- Farkas 지배식의 힘·토크 극한과 수치 적분, IFR의 운동량·각운동량·에너지·분기 연속성은 자동 시험 대상입니다. 원문과 구현 선택 근거는 `docs/decisions`와 모델 설명서를 보세요.
- 겹침으로 완전히 사라진 칩, 빠른 회전의 앨리어싱, 충돌 순간 흔들림은 알고리즘만으로 없는 정보를 만들어 해결할 수 없습니다. 수동 보정·제외·재촬영 판단을 기록합니다.

## 저장 파일

- `project.json`: 영상 경로, 시작 승인, 칩별 구간, 수정 이력, 계수용/검증용 구분.
- `runs/.../records.sqlite`: 원시 관측·수동 보정·파생량·충돌 사건을 분리한 전체 기록.
- `runs/.../export`: CSV/JSONL, 그래프, 품질 기록과 요약 Excel.
- `results`: 사용자가 볼 통합 운동 데이터와 영상별 요약.
- `results/계수_측정/.../constants.json`: 사용 영상·프레임, 계수별 상태, 누락 이유, 모델과 코드 버전.
- `results/고정계수_검증`: 계수를 고정한 예측값·관측값·오차.
- `results/작업기록`: 피팅·검증의 완료, 중단, 실패 기록.

원본 영상과 기존 버전 결과를 덮어쓰지 않습니다. 이전 버전의 프로젝트를 사용할 때는 복사본에서 새 분석을 실행하는 것을 권합니다. 계수 파일의 해시가 바뀌면 검증을 막습니다. 이전 결과는 새 설정에 자동으로 맞는 자료가 되지 않습니다.
