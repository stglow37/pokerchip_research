# v6.0.0 사용 안내

Windows에서는 `SETUP.cmd`로 설치하고 `RUN.cmd`로 실행합니다. 설치 의존성 파일은 기존 고정 목록을 유지합니다. 전체 198개 시험 통과는 2026-10-06 Windows CPython 3.14.7의 개발 검증 기록이며, GitHub 업로드 직전 시험·빌드·GUI·CLI 실행은 생략했습니다. [업로드 기록](../../validation/test-records/v6/PUBLICATION_20261007_KO.md)을 함께 읽으세요.

## 달라지는 계산

측정 중심이 있는 흐린 프레임도 일반 프레임처럼 속도·가속도·계수 입력으로 사용한다. 화면과 저장 결과에는 경고 및 영향을 준 칩/프레임을 남긴다. 품질 경고가 사라지거나 자동으로 사람이 승인한 것으로 바뀌지는 않는다. 실제 위치/시간 누락, ID 모호성, 명시적 제외, 모델 밖 접촉은 계속 항목별 계산 불가다. 회전이 없더라도 법선 반발은 계산할 수 있다.

기존 v5 run은 새 계산 정책으로 재분석한다. 원본과 기존 결과는 그대로 두고 새 run을 생성한다. 이 변경은 흐림 자체의 측정 편향을 고치는 기능이 아니다.

## 계수 구하기

영상 용도를 학습/검증으로 나눈 다음 ‘계수 구하기’를 사용한다. 저장 결과의 ‘v6 구간·신뢰도 설정’에서 실제시간 구간 길이(기본 0.25초), 집계 bootstrap(기본 200회), 공통 피팅 비교, 접선 전체 재피팅 bootstrap(기본 0)을 정한다. 현재 설정 변경은 보수적으로 재분석을 요구할 수 있다.

마찰은 구간별로 피팅하고 영상→세션→전체 평균을 구한다. 영상이 긴 사람이 결과를 지배하지 않도록 한 집계 방식이다. 단순히 구간으로 나눴다고 실행시간이나 정확도가 좋아진다고 보장하지 않는다. 법선은 충돌별 원비율을 저장하되 대표값은 전후 오차를 반영한 회귀로 구한다. 접선 두 계수는 여러 충돌의 식별성 검사를 통과해야 대표값으로 제공한다.

`results/계수_측정/<새ID>/`의 constants.json과 기존 측정한_계수.csv에 더해 구간별_마찰계수.csv, 충돌별_계수.csv, 계수_신뢰도.csv, 계수_요약.xlsx를 확인한다. 숫자만 보지 말고 사용 입력·영상·세션 수와 경고/보류 이유를 함께 읽는다.

반복성(분포/표준편차/영상 제외 민감도), 조건부 추정 불확실성, 별도 영상 고정 예측 오차를 구별한다. 세션이 하나면 영상 간 변동이지 독립 세션 검증이 아니다. 독립 묶음 하나면 집계 신뢰구간은 비어 있다.

CLI 예:

```powershell
python -m pokerchip study-train PROJECT
python -m pokerchip study-test PROJECT CONSTANTS_JSON
```

기존 실행 명령과 import도 유지한다. 분담 분석은 [통합 안내](DISTRIBUTED_ANALYSIS_V6_KO.md), 필드는 [추가 계약](../methods/V6_DATA_ADDITIONS_KO.md), 판단 근거는 [ADR-008](../decisions/ADR-008-v6-warning-and-integration.md)을 따른다.

## 알려진 한계

개발에 사용한 ZIP 관측 재계산은 새로운 영상의 독립 정확도 검증이 아니다. 바닥 마찰 모델의 계수 안정성, 흐림/가림 편향, 실제 시간·거리 검증은 별도 실험이 필요하다. 접선 전체 재피팅은 많은 최적화를 반복하므로 기본 비활성이다. 원본 영상 재추적 시간과 이미 저장된 관측 재계산 시간을 혼동하지 않는다.
