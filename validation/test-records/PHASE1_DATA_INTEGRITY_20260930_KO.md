# 1단계 데이터 무결성 작업 기록

작성일: 2026-09-30  
상태: 구현 및 자동 회귀시험 통과, 실제 독립 영상 검증은 후속 단계

## 목적

v4 개선 계획의 첫 단계로, UI 확장 전에 연구 결과가 잘못 재사용·연결되거나 한 측정 채널의 결측이 다른 물리량까지 불필요하게 차단하는 문제를 수정한다. 물리식 자체는 이번 단계에서 변경하지 않는다.

## 반영한 항목

1. canonical source를 measurement / analysis / physics / export 단계별로 해시한다. 현재 구조 이동 뒤 `application/`만 해시하던 범위를 수정했다.
2. 영상별 수동 수정은 해당 영상의 analysis key에만 포함한다. 전역 수정은 계속 모든 관련 영상을 무효화한다.
3. 사건 승인·제외가 반영된 최종 사건을 운동학 장벽에 사용한다. `excluded`와 `noncontact_pass`는 장벽에서 제거한다.
4. 연구 피팅과 탐색 미리보기 모두에서 모든 사건 주변을 일괄적으로 ±6프레임 제외하던 정책을 제거했다.
5. 후보 범위, 전후 적합 범위, 가능한 경계 범위, 명시적 사용 불가 범위를 서로 다른 사건 필드로 기록한다.
6. 중심 수동 수정 뒤 과거 중심 기준 회전·표식·경계 경고를 정상값으로 유지하지 않는다. 위치는 수동 확인으로 남기고 회전은 재검토 상태가 된다.
7. 피팅은 run에 고정된 측정 설정과 현재 프로젝트의 질량·관성·물리 모델을 명시적으로 결합하고 두 설정 해시를 provenance에 남긴다.
8. 위치 기반 법선 반발 자료를 회전 포함 IFR 자료와 분리한다. IFR 단계는 별도 법선 단계의 `e_normal`을 고정해 사용한다.
9. 비동기 작업에 job/project/folder/settings 식별자를 고정한다. 다른 프로젝트 또는 변경된 설정에는 완료 결과를 연결하지 않는다.
10. 프리뷰 실패에도 요청 token을 포함해 오래된 오류가 현재 작업 상태를 해제하지 않게 한다.
11. run·피팅·계수 bank·고정계수 검증에 물리 모델 식별자, 식 버전, 적용 범위를 기록한다.

## 추가한 회귀시험

- 단계별 코드 manifest가 canonical measurement/physics 코드를 포함하고 UI를 제외하는지 검사
- 다른 영상 수정이 현재 영상 analysis key를 바꾸지 않는지 검사
- 제외된 비접촉 사건이 운동학 장벽이 되지 않는지 검사
- 넓은 검색 후보 범위가 아니라 정제된 충돌 경계 범위를 장벽으로 쓰는지 검사
- 중심 수정이 오래된 회전·표식·경고를 무효화하는지 검사
- 회전 없이도 위치 기반 법선 자료가 생성되고 IFR는 보류되는지 검사
- 측정 스냅샷을 유지하면서 현재 물리값을 피팅에 사용하는지 검사
- 기존 한 충돌 피팅 시험을 회전 결측 법선 추정 사례로 강화
- IFR 피팅에 고정한 법선 반발계수가 후속 최적화에서 바뀌지 않는지 검사
- 작업 도중 설정이 바뀌면 비동기 결과를 현재 프로젝트에 연결하지 않는지 검사
- 오래된 프리뷰 실패와 현재 프리뷰 실패가 분석 작업의 busy 상태를 해제하지 않는지 검사

- `run_cli.py --help`: 정상 종료 및 전체 명령 등록 확인
- `QT_QPA_PLATFORM=offscreen`에서 실제 `MainWindow` 생성·종료 확인

- 테스트가 만든 `work/pytest*`와 소스의 `__pycache__` 정리

## 후속 단계로 남긴 항목

- 배포 기준 환경인 CPython 3.12에서 동일한 126개 시험 반복 실행. 이번 검증은 프로젝트 지원 범위 안의 CPython 3.13.3에서 수행했다.
- 새로운 독립 실제 영상으로 관측·사건·물리 수치 및 연구 결론 검증
- 사람이 확인한 접촉 전후 경계를 편집하는 UI와 schema 3.0. 현재는 필드를 분리해 기록하지만 이전 프로젝트는 후보 범위를 보수적 장벽으로 사용한다.
- 모든 그래프에서 시간·거리·회전 상태와 단위를 더 명확히 표시하는 C11/UI 작업

1단계 코드 안전 패치는 자동 시험 기준을 통과했다. 이는 실제 영상의 독립 정확도나 물리계수의 외적 타당성을 뜻하지 않는다.
