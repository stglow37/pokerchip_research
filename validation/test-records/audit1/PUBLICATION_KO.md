# audit1 코드 게시 범위 — 2026-10-10

v6.0.0 커밋 `8010378284e9141a1a57a4ad1cf21d343039db89` 위에 연구용 개선분을 별도 브랜치로 게시한다. 기존 main과 릴리스 태그는 변경하지 않는다.

## 포함 범위

- 초반 격자가 가려졌을 때 후반 영상 프레임을 추가로 확인하는 평면 보정 복구. 동일한 격자 합의·오차 기준을 적용한다.
- 원형 접촉면의 비균일 마찰을 적분하는 자유운동 후보 API와 회귀시험.
- ADR-009/010, 데이터 사전, 사용법, 버전 표기, 검증 기록.

관측·피팅·평가를 수행한 별도 분석 묶음과 원본 영상, 드라이브 식별자, 상세 관측 데이터, 로컬 경로, 추적 데이터베이스는 이번 코드 게시에 포함하지 않는다. 분석 묶음의 별도 스크립트 기능이 프로그램 GUI에 모두 통합되었다는 뜻은 아니다.

## 검증과 한계

개선본의 기존 전체 시험은 Windows CPython 3.14.6에서 207개를 통과했다(`pytest.log`). 게시용 새 체크아웃의 재실행 결과는 `publication_pytest.txt`에 기록한다. 원본 소스와 게시 코드의 비교는 줄바꿈 차이를 제외하고 수행한다.

기본 Farkas/IFR 계산 경로와 schema 2.0은 유지한다. 비균일 접촉 모듈은 별도의 연구 API이며 충돌·들림을 처리하지 않는다. 회전 증가를 허용하는 수학적 후보지만 보류 영상 예측에서 일관된 개선은 확인되지 않았다. 시험 통과를 독립 물리 정확도 인증이나 사람의 영상 승인으로 해석하지 않는다.

기존 사용자 작업 폴더, 원본 ZIP·영상, 고정된 분석 계수·평가 기록은 변경하지 않는다. 새로운 물리 모델의 평가에는 새 검증 자료가 필요하다.
