# v6.0.0 GitHub 업로드 기록 — 2026-10-07

## 통합 범위와 확인 정책

v5 커밋 위의 기존 v6 구현·시험·문서를 함께 main에 통합하고 v6.0.0 주석 태그로 보존한다. GitHub Release는 생성하지 않는다. 이번 추가 변경은 현재 문서·버전 표시와 공개 집계 기록이며 계산식·API·데이터 계약을 추가 변경하지 않는다. 기존 v4.5/v5 기록은 보존한다.

[개발 검증 기록](REPORT_KO.md)의 2026-10-06 Windows CPython 3.14.7 전체 **198 passed in 78.64s** 및 GUI·CLI·pip check 기록을 유지한다. 사용자 요청으로 업로드 직전 시험·빌드·GUI·CLI 실행은 생략했다. Git diff 공백, 커밋 포함 파일, 원격 커밋/태그와 병합 이력을 확인하는 것은 소프트웨어 재시험과 다르다. 원본·연구 프로젝트 전체·SQLite·캐시·가상환경은 업로드하지 않으며 공개 상태와 라이선스 정책은 변경하지 않는다.

## 10영상 결과: 잠정 계수와 조건부 검증

로컬 연구 프로젝트의 저장 JSON/CSV를 검토한 집계다. 원 영상 프레임 전수 판독, 새 영상 추적 또는 독립 참값 검증은 이번 검토에서 수행하지 않았다. E117~E126 10영상/1세션 모두 처리 완료. 선택 구간 합계 2,154프레임, 칩별 관측 기회 4,308개 중 관측 4,260개(98.89%). 이는 검출 정답률이나 계측 정확도가 아니다.

E119~E126 8영상으로 추정한 **잠정 계수**:
- 바닥 마찰 0.1502258796: 자유운동 54구간/8영상/1세션, 재표본 95% 구간 [0.1191927623, 0.1853385476].
- 법선 반발 0.7590305884: 충돌 7건/7영상/1세션, 재표본 95% 구간 [0.7112319056, 0.8572659330].
- 접선 반발 -0.4702988926, 충돌 마찰 0.0365170721: 충돌 5건/5영상/1세션. 접선 전체 재피팅 bootstrap은 비활성(requested=0)이며 95% 구간은 미산출.

재표본 구간은 같은 세션 안의 영상 간 변동(within_single_session_between_videos)이다. 거리·시간 공통오차, 모델 편향 또는 세션 간 재현성의 전체 불확실성이 아니다. 네 계수 모두 독립 정확도 미검증이다. 앞선 개발 ZIP 3영상 결과와 입력 묶음이 다르므로 계수 차이를 정확도 개선으로 해석하지 않는다.

E117·E118을 비교용으로 분리해 자유운동 10구간·충돌 2건을 평가했다. 저장된 원본 해시의 학습/비교 중복은 없고 parameters_refitted=false이며 전후 계수 해시가 동일하다. 자유운동은 첫 12관측 프레임으로 초기 상태를 추정하고, 충돌은 관측된 직전 상태에서 예측한다. 동일 촬영 세션의 조건부 영상 분리 검증이며 전체 운동의 end-to-end 또는 독립 세션 검증이 아니다.

자유운동 위치 2D RMSE는 0.074~16.715 mm. E118 첫 평가 구간은 칩1 16.715 mm/각도 29.314도, 칩2 14.297 mm/33.018도이며 E117 칩2 첫 구간은 12.852 mm/11.680도다. 작은 오차의 일부 구간에는 weak_free_motion_signal 경고가 있다. 충돌 후 속도 2D RMSE는 E117 0.072111 m/s, E118 0.126540 m/s이며 각속도 RMSE는 각각 0.657223 및 1.880121 rad/s다. 합격 기준을 정하거나 물리 정확도 합격으로 선언하지 않는다.

## 경고와 다음 연구 작업

거리 보정은 provisional, 시간은 declared다. 충돌 후보는 review_required이며 승인되어 피팅 가능한 사건은 0개다. 미검토 후보의 탐색 계산에는 human_review_incomplete 경고가 유지된다. 계수 입력 경고 관측 24개와 전체 영상 검토 대상 264프레임은 다른 집계다.

계산된 바닥 마찰 54구간 중 경고 포함 28구간, 약한 운동 신호 20구간, active_fit_bound 4구간. 접선/충돌 마찰의 국소 추정 상관은 약 -0.903이며 각각의 정밀한 분리 추정으로 해석하지 않는다. E125는 검토 대상 201프레임, 바닥 경계 관련 162행으로 우선 검토 대상이다. E123은 관측 100%여도 충돌 전후 상태 부족으로 충돌 계수에서 제외된다.

다음 연구 작업은 원본에서 E125 사용 구간·바닥 경계와 E118 및 E117 칩2의 큰 예측 오차 구간을 검토하고, 개발에 사용하지 않은 촬영 세션에서 독립 거리·시간 기준으로 고정 계수를 평가하는 것이다.
