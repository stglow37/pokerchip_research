## 원 ZIP 관측 비교

입력: `<로컬 연구 자료>/분석 결과 1006.zip`. ZIP은 읽기 전용으로 열고 raw 관측/프레임만 별도 SQLite로 복사했다. 기존 ZIP·영상·분석 결과는 덮어쓰지 않았다.

재현 스크립트: `validation/run_v6_zip.py ZIP NEW_DESTINATION`. 최신 비교 근거는 `work/v6-policy-complete-20261006/v6_zip_comparison.json`이다. 모든 프레임을 새로 영상 검출한 실행 시간과 구별한다.

- chip_2 221: vx=-0.89334628 m/s, vy=0.53801204 m/s, ω=3.78057999 rad/s. 원인 참조 221.

학습 3개 영상/1개 세션에서 최종 잠정 μ_b=**0.18201687**, e_n=**0.67513784**. 마찰 후보 16구간 중 미수렴 1개와 rank-deficient 1개를 제외한 14구간을 집계했다. 특이 구간의 후보 μ_b≈0.97500844는 진단으로 보존했다. 중간 0.22946354는 특이 후보를 포함한 감사 전 값이며 최종 대표값이 아니다. 이전 v5 μ_b=0.28146508과의 차이는 단순 정확도 개선의 증거가 아니다.

접선/충돌 마찰은 환산 가능한 충돌이 2개여서 보류했다. 후보의 추가 승인이나 0 채우기로 합격시키지 않았다. 집계 bootstrap은 각 200회이며 하나의 세션 내 3영상 변동으로 표시한다. 조건부 고정 검증은 별도 E117 영상으로 수행했다. 같은 세션이며 개발에 사용한 ZIP이므로 독립 물리 정확도 보증이 아니다.

## 남은 검증 범위

[요구사항별 인수 확인](../../../docs/development/V6_REQUIREMENTS_KO.md)을 마쳤다. ZIP 재계산은 기존 dataset/preview 경로 및 제출 세션 검사 보완 전에 수행했으며 주 계수 집계 경로의 계산식과 관측 사용 정책은 해당 보완에서 변경하지 않았다. 고급 접선 전체 재피팅은 단계 호출·선행 계수 전달·명시적 제외 유지 시험을 수행했지만, 실제 ZIP은 적격 접선 사건이 부족하므로 충분한 조건의 새 실제 촬영 자료에서 전체 접선 계수의 불확실성 coverage를 검증하지 않았다. 이는 소프트웨어 구현 성공과 독립 연구 정확도의 차이다. 원 영상 전수 재추적과 지원 Python 버전/DPI/장시간 운영의 추가 반복 검사는 이번 인수 범위에 포함하지 않았다.
